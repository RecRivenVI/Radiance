# 原始城市存档升级

## 目标

只读恢复已登记的原始城市，在不加载 Radiance、探针或第三方模组的 NeoForge 客户端调用原版 Optimize World，不清除缓存。逐区块核对数据版本、可读取性、区块集合与非空气方块数量，再冻结阶段 3 城市夹具。

## 运行

从仓库根目录执行：

```powershell
.\gradlew.bat :render_diagnostics:upgradeCityFixture
```

自动客户端静音、1920×1080。复用现有 Java agent 的输入隔离；不接受服务端 EULA、不进入世界，不执行性能采样。原始存档路径只从本地输入读取。

## 通过标准

实际加载模组仅 minecraft 与 neoforge，原版优化状态完成且处理数相符；所有原有区块可读取、版本完成升级，没有大面积方块减少或日志错误。原始 ZIP 哈希不变，升级夹具逐文件 SHA-256 读回一致。失败保留副本并停止，不自动重试，不将此检查替代城市目视验收。
