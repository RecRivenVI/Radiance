# Voxy 远景接入回归

## 目标

在静音、1920×1080 的独立实例验证真实 Voxy 摄入、CPU 模型和压缩网格、Vulkan 持久场景、资源重载及世界退出／重进。只检查功能，不采集或比较性能。使用原版地形、cutout、玻璃、水及发光代理，Voxy 测试半径为 512 方块，近景视距为 4；这些是显式的功能用例设置，不改变产品默认设置。

## 运行

先完成本体与 Extra 的配套构建、探针构建以及打包运行参数生成，保持已登记输入不变。`<本体包>` 与 `<Extra包>` 是待验证的冻结发行 JAR 绝对路径。

```powershell
python -B -X utf8 components/render_diagnostics/benchmark/run_voxy_validation.py --core <本体包> --extra <Extra包>
```

只有使用者明确批准本轮存储放宽时，额外传入 `--workspace-limit 20`；22 GiB 例外单独使用 `--workspace-limit 22`，不能由旧轮授权推导。默认仍执行 16 GiB 软上限检查；不写日常实例或 Prism，不测性能，不注入桌面输入。

## 通过标准

日志确认 Voxy 的 GL renderer 与 ModelStore 未创建，存储租约、模型及真实压缩区段实际推进；原生 GPU 构建已记录且世界场景包含远景实例。重载后旧 epoch 被拒收，正常退出／重进后新 session 生效，没有悬空引用、崩溃报告或设备丢失。结果文件记录实际执行的步骤与计数；命令返回 0 或短时未崩溃本身不构成通过。视觉效果仍需使用者验收，不声称性能改善或长期稳定性。

七个阶段覆盖 Vanilla PT 初始摄入、远处来源、近远景返回、资源重载与旧 epoch 拒收、Advanced、实际来源修改和世界退出重入。用例含叶片／草、水、玻璃、普通半透明、熔岩和发光方块，以及含水台阶／楼梯和常量染色树叶；材质类别及真实选中发光候选必须有正计数。各检查点读取真实来源模型表，分别确认无自身染色的含水方块、常量染色和自身群系染色均已摄入，翻译后的索引与颜色表有效。计数不代替颜色、接缝、噪声与动态视觉的人工验收。

当前续做组为 `result/water-history-20261029/`，历史设备丢失停止标记保持原样；本组发生设备丢失后不再自动启动。启动前核对产品与 Extra 探针不存在重叠 Java 包，避免模块解析失败被误记为世界功能结果。

初始阶段须实际持续移动至少 1 格，记录相机移动距离；显式启用的 Native 历史检查必须在运动帧校验远景矩阵对应着色器上一帧相机，并输出通过记录。水面使用配套发行包的默认动态水面设置，在两套内建 PT 中运行；自动检查不代替波动、接缝和抖动的目视验收。

资源重载与重入须等待材质和光源发布完成；初始区只要求实际存在的熔岩发光，远处摄入后要求多种发光来源。源修改必须在客户端摄入范围内，确认新方块已到达、模型及 Native 构建均推进，不能只等待固定秒数就算通过。
