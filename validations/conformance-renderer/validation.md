# 原版 renderer 替代对照

## 目标

沿当前 Target 的实际对象状态，比较独立原版 renderer 与替代请求的部件、顶点、层顺序、颜色和发光；覆盖不同 partialTick、受击、重载和来源变换资格。按来源登记一致、有差异或无法比较，不以注册表数量宣称全部替代。

## 运行

从仓库根目录执行：

```powershell
.\gradlew.bat :version:1.21.1-neoforge:distributedJar :version:1.21.1-neoforge:probeClasses
.\gradlew.bat :render_diagnostics:runEntityTakeover -PentityTakeoverCase=replacement
```

使用项目内 1920×1080 静音纯原版副本，不操作 Prism。对照代码只在探针配置启用，正式性能窗口关闭。结果保全后回收自己的复制环境；自然设备丢失立即停止，不自动重试。

按实际来源逐项比较：玩家双模型、披风／肩上鹦鹉／耳饰、装备与 foil、头部物品、鱼类模型选择、动物携带物、船型与受击摆动、物品框／掉落物、BER 及活动状态。渲染前事件临时换成未登记模型另有反例，要求修改后的输出与原版一致、无直接资源、无重复执行。

## 通过标准

每个实际替代来源与原版独立输出比较，位置误差不超过 3e-5、法线误差不超过 5e-5，其余材质字节、层顺序与顶点数相同；未替代来源逐项说明。动画状态变化与重载不能冻结。功能输入一致不代填最终视觉、长期稳定性或设备丢失根因。
