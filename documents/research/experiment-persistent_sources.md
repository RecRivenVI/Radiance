# 持久来源与未受光材质输入验证

2026-10-26，承接 130、131、132 号已批准任务。来源层已经补齐稳定定义、绑定和姿态复用，以及原版特殊请求；本记录区分源码实现、实际进入、自动对照、性能与尚未进行的人工体验。前次共同区段的收益不用于证明本轮实体优化。

## 问题

已有模型和 Native 实例驻留，仍有重复部件树整理、图层解释、绑定和文字布局。部分原版特殊状态保留完整 renderer，Sable 中普通实体未共用直接入口；Native 缺少显式端点插值。世界材质还混有仅用于光栅的面向明暗和 lightmap，并将部分无效照明作为缓存变化。

## 方法

基线固定为异常修复后的 Core `53dd8834e178884fc839073afba04fd5597239c93d19004b8866b29f27a240aa` 与 Extra `329c0fee177c7f39bad474f13053606b31bf556cc20814edf9422ff8dbb37b9a`。沿用冻结的 129 城市副本、32 视距、1920×1080、静音和原有画质；另用原版加 Extra 的实体／文字密集夹具检验来源工作。功能探针的双路径执行不进入性能窗口。

源码和日志回查入口为 `components/render_diagnostics/build/source-scene/`；真实客户端证据在 `validations/conformance-takeover/result/persistent-sources-130/`。保留每次失败及实际加载身份；设备丢失停止，不自动重试。使用者本日将验证目录上限正式提高到 8 GiB，并允许在容量预算内自主安排候选、不限制套数；仓库与外部目录上限仍有效。

## 发现

### 来源和执行职责

`SourceBindings` 归属实际实体、BER、粒子或破坏进度对象；模型定义、纹理代际、稳定绑定及历史身份不再由本帧绘制序号单独决定。重载和删除使旧来源失效，当前批次已引用的几何继续保留至既有退休边界。

`VanillaPoseMemo` 采样当前模型公开姿态、可见性及子树结构；不变节点复用独立快照，只组合改变的节点和依赖父节点。模型可以被多个对象轮流使用，旧对象的结果不引用随后被改写的模型字段。动画数学和必要回调仍执行，不能将轻量姿态采样描述为完全事件驱动。

稳定图层计划、局部属性和字体布局分别维护。统一颜色、受击覆盖、UV 变换与姿态可独立更新，真正逐面差异仍在网格中。合法非均匀仿射使用对应逆转置法线；不支持的消费者或实际预算不足时精确执行，不省略内容。每个几何的 Native appearance 由 384 增至 432 字节，是明确的资源代价。

### 原版特殊来源

- 活塞、下落方块和破坏覆盖使用实际世界位置、模型数据、邻域几何与染色依赖；简单、加权及 multipart JSON 模型图按实际子模型资格判断。合法空网格不作为异常。
- 末影龙死亡射线、连接水晶光束和水晶目标光束均有独立请求；真正变化的死亡射线复用原版生成算法，不能称为全部静态实例。
- 地图图像、标记及文字有资源更新；第一人称保留原版手部／使用动作数学，手臂、袖层、物品和地图叶子改为明确请求。
- `MobAppearanceParticle`、`ItemPickupParticle` 的嵌套模型归属粒子，保留局部坐标、alpha、发光及顺序；火焰、牵引绳和调试框只执行所需附属算法，不让整个主体退回。
- 世界文字按来源保留布局及字体页；混淆文字实时求值。不是逐字符建立 TLAS 实例，GUI 字体路径不变。

纯原版 `functional/core-20261026-164057` 已实际对照全部 155 个注册来源，并额外覆盖：活塞三状态、有效地图更新、龙死亡 1／80／190、目标光束、19 种第一人称状态各三插值点、18 个嵌套粒子样本、60 个含邻域变化的破坏覆盖样本、F3+T 后公开部件增删和非均匀姿态。它是 132 前的候选证据；不能自动转为 132 后的材料语义通过。

贴花 UV 单独允许 `1e-6` 的逆姿态往返误差，依据实际约 `1.2e-7` 偏差；位置 `3e-5`、法线 `5e-5`。普通材质、颜色及非贴花 UV 仍按原判据，未以最终 RGB 平均差代替检查。

最终 API 5 本体的 `functional/core-20261026-192152` 再次完成以上特殊状态与 155 个来源的独立对照，包含 285 个世界物品样本、18 个嵌套粒子样本、60 个方块／覆盖依赖变化样本、19 组第一人称动作及重载；字体寿命违规为 0。它对应最终产品的真实加载身份，不能用接口新增或注册数替代这些执行结果。

### 共同空间和资格边界

`RenderSpace.motion/sample` 使用显式 TRS 端点、来源时间、最短弧四元数和同号非零缩放；`pose` 切回来源最终姿态。真实 JNI 已验证端点推进、最终姿态恢复及无关空间版本稳定。Sable 保持最终 renderPose，不重复插值；内含、跟随和乘坐分别解释，捕获附件保留必要世界变换。

初次组合测量中，Veil `RenderType`、Create armor／font accessor 和 Custom Skin Loader 等未审阅修改触发安全回退。实际 Sable 2.0.6 包内嵌 Veil 4.3.2，不能将它描述为没有 Veil 的独立组合。

随后只核对当前发行字节的必要修改：Sable 的睡眠与名称牌姿态由 Extra 回调接到原求值位置；其 lightmap／剔除方法和牵引绳仍执行已有来源逻辑。Veil 的工厂与 append-only 状态扩展按实际追加项检查，只允许本来就排除的动态缓冲步骤，未知状态继续完整执行；模型管理器与 Create 字体／盔甲 accessor 只是新增入口。Create 自定义盔甲修改仍通过原图层的 `actual.render()` 执行，没有重写成普通盔甲。登记逐类 SHA-256，不按模组名整体放行；其他修改继续安全回退。对应 API 升为 5，Sable 和完整组合的新验证结果分别记录。

`functional/sources-20261026-191646` 是 Sable＋内嵌 Veil 的通过用例：真实 plot 的内含实体进入共享直接路径，跟随插值、乘坐豁免、退出与重入、睡眠／名称姿态均对照实际来源公式；未知追加状态拒绝静态解释，世界保留真实 EAST 法线、预览保留来源向上法线。`functional/sources-20261026-191916` 是完整组合的通过用例，实际进入 Flywheel 模型／实例并完成选择后删除的真实 JNI 回归、重载与正常保存。两者均未发生设备丢失；未登记的粒子、导管、玩家及其他修改仍按实际资格回退，不借本轮整体放行。

中间三次 Sable 失败分别保留实际缺失接口登记与探针前提错误的证据。最后一次在 Sable 专项已经通过后，因运行器误要求未安装的 Flywheel 而结束；仅修正来源选择，完整组合仍检查 Flywheel 的真实模型与实例。没有删去失败证据，也没有降低对应来源的通过条件。

### 剥离光栅照明

世界方块在原版 lightmap 和固定面向明暗的计算调用处跳过，AO 不用于 PT 顶点颜色；保留实际世界、可见面、模型数据和生物群系染色，不用无光世界替身影响自定义几何。原有从已受光颜色除去明暗的处理取消。

局部模型、文字、绘画、粒子和动态捕获在来源适配时归零 packed light，并移出相应定义／绑定变化依据。纹理颜色、染料、皮肤、受击覆盖、附魔、alpha 和显式发光不随之删除。Flywheel 的材质 lightmap 不再进入通用实例参数；现有 Native 世界 shader 已不应用其光栅光照。

粒子只解释已审阅的原版发光方法，在执行该方法时排除基础环境亮度；普通满亮 UV2 不作为通用发光证据。未知修改不借用此结论。固定的素材／粒子艺术颜色不因“亮度”名称删除。预览继续采样原光照和面向明暗，与世界定义分开。

实际 Sable 包还会用向上法线表示“不受固定面向明暗影响”的面。这是光栅模拟手段，不是真实法线；Extra 在世界 bulk 入口拆去该包装，预览保留。必要的源修改、追加状态和 getter-only 接口分别按实际类字节核对，不将整个 Sable／Veil 模组视为已证明。

最终纯原版用例在两种相关原版实验设置下均记录世界光照查询 0，预览分别 210／94 次；仅改环境光照时资源身份稳定，改 tint 时材质随之更新，普通表面 emission 为 0。普通烟雾为 0，已审阅 Lava／EndRod 明确发光为 15。这证明对应输入语义分离，不代表所有第三方自定义颜色都可自动辨别，也不要求最终 PT 画面不随真实照明变化。

收尾自审发现荧光墨囊文字只有明确的来源全亮标记，没有相应物理发光意图。补充在 `SignText.hasGlowingText()` 的实际绘制作用域内提交 emission；普通文字不因满亮 UV2 发光，木质主体不被作用域覆盖，预览不受影响。原 `renderSignText` 与新的来源请求共用这一解释；后续结果单列，前面的性能包不是这项补充的最终身份。

最终 `functional/core-20261026-200015` 再次通过原版完整功能对照与字体重载。两种原版细分设置下，32 个真实文字顶点按普通→荧光→普通分别记录 emission 0→1→0；该结果证明明确发光进入标准世界材质，而非 GUI 增亮。全亮到物理发光仍复用已有 Native 材质执行，没有创建文字专用照明路径。

132 前城市基线与候选站立分别为 21.176／21.188 ms，移动为 24.102／24.725 ms；不足以证明净收益。候选加载窗口与一次探针 Gradle 编译重叠，不用于干净加载收益结论。先前 129／共同区段的收益不与这些数值累加。

本体 `spotlessApply check verifyRelease verifyCompliance --strict` 通过；Java 产品 302、SERVICE 13、JNI 4、探针 48 项无失败。原生 78 项和 GPU 23 项通过，最后文字补充未改变其 Native 字节，按影响复用；Extra 的格式、98 项测试、发行核验、严格合规和探针编译通过。日志分别为 `task132-sign-gates2.log`、`task132-api5-gates.log`、`task132-extra-final.log`。最终文档检查另保留记录。

唯一配套清单为 `validations/conformance-takeover/result/persistent-sources-130/candidate.json`，含本体／Extra 的 SHA-256、两仓源码快照、实际运行脚本、测试回执及匹配的 DLL／PDB 身份。冻结通过移动最终 JAR 与符号文件避免无用副本；旧基线和失败证据不覆盖。一次城市启动前因超过工作区软上限被预检拒绝，未启动客户端；只将已验证 SHA-256 相同的旧生成副本替换成保留文件的链接，未扩大容量上限或删除唯一构建。

## 结论

本轮已形成自动验证过的配套整体候选：来源持续维护稳定定义、绑定、姿态及文字布局；已知原版特殊状态、Sable 共同入口与可选 Native 插值有实际执行证据；世界材质剥离无效光栅照明并保留真实颜色、覆盖和明确发光。没有宣称所有第三方修改或所有原版函数都已消失，必要动画、算法和未知来源回调继续执行。

性能结论仍是未证明稳定整帧提速，且存在退步及初次加载长帧样本。来源工作量减少并没有兑现为同等 FPS 收益；不据此承诺 60 FPS，不用继续扩大运行寻找有利结果。当前交付的价值是来源架构和语义闭合，后续性能投入应重新根据实际关键路径决定。

人工仍需体验共享模型的不同对象与动画、地图／单双手使用、荧光和普通文字、Sable 的运动／睡眠／名称／进出结构，以及 F3+T 和离开重进。自动几何、材质和公式对照不代替这些动态视觉结果。使用者随后追加授权完成后投放配套 Prism，投放身份与结果以候选清单关联的回执为准，不启动游戏。不提交、不推送，不恢复 GUI／FG、VSync、设置或其他暂停事项。
