# 接管平台与原生执行重组

2026-10-24，按使用者批准的 127 号计划实施步骤一至四。当前已具备本体、独立 Extra 与组合候选；自动功能验证与人工验收分开，未开展步骤五、六。

## 问题

原版求值、第三方适配、通用执行及源格式解释混在同一产品中。模型缓存不等于实例持久化，GUI 固定效果流程也缺少清楚的读写依赖。目标是在保留既有行为与区块流水线的前提下，将正式生产链接到明确的平台、所有权及版本边界。

## 方法

基线为候选清单记录的 `7209963`，不改 Git 历史。先迁移可恢复的源代码和探针，再接通公共平台、通用实例／LOD 输入和 Native 效果执行，最后使用独立构建与实际发行包运行。权威架构与数据寿命集中在[原生与平台架构](../design/architecture-native_renderer.md)，不另建一份接口定义。

优先风险是早期 Mixin／JNI 绑定、重载和世界卸载期间的资源寿命，以及 GUI／世界效果与 FG 顺序。采用原有源 renderer 输入对照、真实源码布局、Native／GPU 合同和三种安装状态的功能会话。没有性能采样窗口、故障注入、用户输入注入或外部实例操作。

所有日志、失败和交付身份位于 `validations/conformance-takeover/result/platform-reorganization/`；唯一候选清单是其中的 `candidate.json`。本体与 Extra 的源码分别管理，不因父仓库忽略而把 Extra 视为已入历史。

## 发现

### 正式路径

本体内置 Vanilla／NeoForge 求值；`WorldScene`、`WorldLines`、`RasterDraws`、`WorldView`、`LocalModelBatch`、`InstanceScene`、`LodScene` 与 `ScreenEffects` 是真实生产入口。现有区块版本发布、模型／纹理缓存、查询规则和 GPU 退休继续工作，不复制成第二套场景数据库。

来源所有者的稳定实例保留在 Native，Java 只留弱身份及最近参数的变化日志。预算拒绝驻留时仍完整瞬时绘制，离开视图不会误删对象。真实组合的后段记录为 265,686 次参数接受与 1,876,615 次视图选择；这是该会话的工作计数，不是 CPU 时间、覆盖率或 FPS 收益。

第三方源格式已迁入 Extra：八种 Flywheel 布局转通用参数，Voxy 的位布局转通用节点／面／模型投影。真实组合记录到两个模型、40 个 Flywheel 实例及四个 Sable 子世界；Voxy 有实际 cut 和资源发布，重载后归还旧 lease 并创建新会话。Simulated／Veil 注册已激活，不据此宣称弹簧、图解与所有 GUI 已逐项目视通过。

蜘蛛效果保留四次模糊及最终复眼合成，其他已支持效果由同一执行器处理；图解预览按职责分出。Vulkan GUI、压暗及全屏模糊关闭 FG 的既定政策不变。按需状态页显示来源、直接／捕获、驻留／瞬时及实际 CPU 消费，关闭即停止，未出现不计通过。

### 构建与自动验证

- 本体：先 `spotlessApply`，再 `check verifyRelease verifyCompliance --strict`，成功；实际原生 INSTALL、76 项非 GPU 和 23 项 GPU 合同通过。最终门槛复用已安装 Native，不重复全量编译；JNI、生成 ABI、发行结构和探针排除检查通过，严格合规 0 失败／0 警告。
- Extra：固定本地 Maven API 独立构建，`spotlessApply`、`check verifyRelease verifyCompliance --strict` 成功；没有父源码依赖或本体内嵌。自己的 CI 仅执行不需要本地 API／输入的仓库检查，不上传二进制。
- 普通 JVM 测试最初缺少本体的 Minecraft 访问变换，已从固定开发 JAR 提取，未复制声明。迁移前的测试路径和两个探针测试遗漏已修正；保留首次失败日志。

### 实际会话与失败边界

最初一次在进入世界前因探针仍注入旧 `updateWorldUniform` 方法失败，退出又记录 `sl.reflex.dll` 的 JVM 访问异常。没有 `VK_ERROR_DEVICE_LOST` 或 GPU 转储；保留 Java 崩溃报告及 hs_err，不将二次退出异常定为 GPU 根因。修正探针到真实 `WorldView.submit` 后追加会话，没有重复运行未修改的失败配置。

之后纯本体、Extra 无目标模组、实际目标组合三个会话均正常进入世界，执行原始模型对照、状态页面、三种相机效果、F3+T 及保存关闭。实际加载 DLL 与各自发行包核对；最终组合明确匹配清单中的两份产物。截图已查看：GUI 字体／分页、场景、手持物、Create 机械及 Sable 平台可见，重载后继续绘制；完整动态视觉仍由使用者验收。

前两会话使用旧小型夹具的地层设置，只支持受控源数据与生命周期结论。组合会话的新正确性夹具将地面设为 Y63，使 Y64 附近对象位于地面上；没有改历史性能输入，不作跨会话 RGB 或性能比较。独立原 renderer 的几何／材质比较仍在同一会话内进行。

### 代价与未验证

Native 仍按视图组织必要的实例、历史、相机派生数据和 GPU 表，不称完整逐记录 GPU 数据库。新增强驻留模型预算独立于原 LRU；LOD 输入从 8／64 字节扩为 16／224 字节，是可测量的存储与传输代价，未声称免费或已提速。

当前实际会话为 8 视距小场景；本轮未重测 32 视距城市、跨维度、长期稳定性、全部第三方 GUI 或 FG 前台动态视觉。Voxy 只覆盖既有指定构建及当前材料路径，Advanced 灯光等旧边界没有借迁移补写通过。直接接管与保留捕获的逐项边界仍见[覆盖表](../reference/registry-takeover_coverage.md)。

## 结论

步骤一至四已形成可运行整体候选，工程接通与限定自动功能证据成立，人工目视验收和集中性能结论尚未成立。用户入口不装探针、准备后不启动；人工步骤见[验证说明](../../validations/conformance-takeover/validation.md)。

Extra 位于指定独立仓库，尚无提交或远端；父仓库也未暂存、提交或推送。本轮首次交付后停止，步骤五、六由使用者后续安排。未改变既定画质、完整 PT 几何、世界查询、线条、发光或 GUI／FG 政策。
