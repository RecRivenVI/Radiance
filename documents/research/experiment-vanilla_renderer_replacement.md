# 原版 renderer 替代实验

2026-10-20 开始、2026-10-21 收口：153 项注册来源及 285 项世界物品组合完成限定原 renderer 输出对照，完整门槛、双分辨率 ABBA 和未启动的人工入口已完成。仍有逐项原执行／模板重放残留；层匹配和拓扑工作减少，但稳定整帧收益未获证明。新增动态目视、全零捕获、GPU 异常根因和长期稳定性均不据此宣称通过。

## 问题

按 [adr-12](../design/adr-12-vanilla_renderer_replacement.md)，替换逐帧 renderer→顶点→捕获及最终三角形匹配，保留原版动画数学、实际状态、所有绘制内容和世界 PT 语义。主要风险是模型变换／颜色遗漏、层绑定顺序错误，以及输入复用冻结动态状态或历史。

## 方法

从实际对象提取状态，调用原模型的 prepareMobModel/setupAnim 与 renderer 的纯姿态求值。共享模型根／部件适配器产生局部资源和变换，不执行原 renderer.render 或 ModelPart.render。特殊消费者未迁移前逐项保留原路径，不执行一遍失败后再重复动画。

原版独立 renderer 与新请求在功能探针中双执行；比较层顺序、数量、位置／法线和全部其他 PBR 材质字节。不同 partialTick、受击及重载分开核对。重型对照不进入性能窗口。测量采用冻结城市、32 视距、1080p／1440p 的至少 ABBA 配对及逐窗干扰记录。

## 发现

中间候选的失败与纠正保持独立：`replacement-20261020-205542` 在实际绵羊附加层请求中触发 Mixin 包辅助类的 `IllegalClassLoadError`，辅助方法已移到普通适配器；`replacement-20261020-210246` 的书本模型根适配因多目标 `@Shadow` 的 remap 声明被 Mixin 拒绝，继而在独立 BER 对照中暴露。已修正声明，后续结果另记。这两次不是设备丢失，均有世界保存证据；不能记作通过。失败原始日志和崩溃报告保留在 `validations/conformance-renderer/result/`。

- 首次预检在 GAME 前失败：自有验证目录名使着色器路径达到 264 字符；文件及发行 JAR 中的对应项都存在。缩短为 conformance-renderer 后启动正常，无设备丢失；失败原始记录保留于该验证 result 下 replacement-20261020-193557。
- replacement-20261020-193727 中，40 个实体来源的三个 partialTick（0、0.37、0.91）和受击变化共比较 28,080 个顶点，位置、法线与其他材质字节一致，位置／法线最大误差为 0。其余 43 个 living 来源保留捕获，46 个实体属于其他绘制族，24 个 BER 和 2 个玩家另列；155 项登记不写成全部替代。
- 同进程完成资源重载、原有公开状态与部件生命周期专项，正常保存并关闭。此结果对应首条替代路径，不能覆盖之后新增的模型层绑定。
- 模型层资源绑定正在实现：源部件／外观声明在局部资源创建时合成，普通帧提交变换；不在每帧世界坐标三角形上发现绑定。新 JNI 输入与多几何资源的 SBT／历史仍须定向验证。

## 结论

### 2026-10-20 中间替代检查点

`replacement-20261020-215143` 已完成 87 个注册来源的独立原 renderer／新部件请求对照，动态物品选择、foil、玩家双模型、装备和轮廓均有实际输出比较；正常重载、保存及 native 关闭。`replacement-20261020-220957` 扩展为 114 个来源一致、41 项捕获，增加船、矿车主体、投射物、床、篝火和可疑方块。后续适配没有混入这些通过记录。

该轮还核对了河豚的 0→1→2→0 模型切换、12 种热带鱼花纹、幼年非均匀变换、头部物品与龙头、鞘翅及受击。事件在资格检查后临时换成未登记模型的反例，与原版输出一致：修改后的模型各执行一次，候选没有直接资源。原始结果的 `preEventModelMutation` 和各来源 `variants` 可回查。位置容差 3e-5、法线 5e-5，其余材料字节精确；这是来源输出对照，最终视觉仍待验。

中间失败另存：211255 的史莱姆凝胶层发现延后提交时丢失原材质作用域，现将材质状态随请求冻结；211814 暴露指南针动态 override 子模型未纳入加载期声明，已沿实际发布的 override 树登记；213136 暴露玩家手持层遗漏 `PlayerItemInHandLayer`，已接同一物品请求。三项均由原版独立输出或直接路径断言发现，纠正后 220957 通过，均非设备丢失。

`replacement-20261020-224012` 的发光物品框输出对照暴露新框体适配遗漏了既有 `GlowItemFrameRendererMixins` 的发光作用域。已在框体和框内物品请求补齐；显式烘焙资源缓存同时区分继承的发光／透射状态，物品请求保留 `HandItemMaterialResolver` 的世界材质继承。225249 已越过发光物品框及其有物品变体，随后停在轮廓比较器：蘑菇层只申请但不输出线条时，两侧合法空批次返回 null；比较器现区分“两侧皆空”与“单侧缺失”，后者仍失败，全局非空线条要求保留。均正常保存、无设备丢失，后续对照另记。

作用域专项构建与单元回归中，最初暴露旧测试夹具把 `SimpleBakedModel.getOverrides()` 设为 null，无法满足当前真实标准模型的非空 override 表；已用 `ItemOverrides.EMPTY` 修正该测试输入，未在产品中加空值放行。`stage6-frame-material-regression.log` 对应配套构建和相关 11 项单元检查通过。原版对照进一步加入相同物品／相同 light 下继承发光 0→0.25→0→1→0、红色染色玻璃，以及活动潮涌核心、陶罐摇摆、篝火物品、考古物品和刷怪笼嵌套实体，结果待本轮运行完成。

最小性能预检的基线窗口为 `performance-vanilla/result/stage6-pilot-A-r32-1080-20261020-221743`：160 个真实帧间隔，均值 62.454 ms，p95 84.482 ms，p99 92.758 ms。只有基线，不据此下收益结论。候选预检曾被探针源码较新拦在启动前；随后固定该基线实际使用的探针供配对复用。正式最终 ABBA 仍待完成。

配对最小样本的中间候选为 `stage6-pilot-B-r32-1080-20261020-222725`：205 个帧间隔，均值 48.650 ms、p95 55.612 ms、p99 63.682 ms；渲染线程 CPU 均值 60.171→48.316 ms。两窗使用完全相同探针且均正常保存关闭。A 窗并行 MCP 进程 80564，B 窗为 117368；整卡利用率均值约 59.9%→37.1%，主队列 GPU 时间约 31.71→17.05 ms。并行负载明显不同，因此不把单次约 13.8 ms 差值当正式净收益，也不外推帧率；只确认该运行器能取得完整、无丢失的配对窗口。B 之后继续增加的来源不属于这个中间候选。

为后续性能样本腾出空间，正常结束于 10-15 的 `conformance-benchmark` 和 `regression-query_visibility` 旧客户端环境已在保留文本证据后移入回收站；不涉及日常实例或外部游戏。

当前结论为：首条路径的来源输入一致；尚未覆盖的原版来源和新绑定后端无法据此比较。性能与最终视觉待冻结后的对应验证。后续边界、逐项覆盖及退出条件见[推进计划](../project/plan-render_takeover.md)，原始结果位于 validations/conformance-renderer/result，不操作外部实例。

`replacement-20261020-232136` 扩大至 144 个来源，与原版一致。覆盖守卫者活动光束、标牌正反文字与发光文字、展示实体的 block/item/text 状态、箭矢抖动、经验球、玩家插箭／蜂刺、激流、计分板名称和已有背景拆分。原始线条请求以其完整位置、颜色、法线与截面坐标系比较，不按 PBR 四边形误解。

`replacement-20261020-233408` 扩大至 152 个来源，与原版一致，新增信标分段、传送门／折跃门活动光束、结构方块边框和隐形方块检查、钓鱼钩与曲线、闪电种子以及幻术师分身。世界物品为 285 项实际组合，加入盾牌、三叉戟、望远镜、箱子／末影箱、旗帜、床、潜影盒、潮涌核心、陶罐和龙头；玩家持用望远镜与盾牌／三叉戟也有独立原 renderer 对照。保留 9 项公开状态反例、资源重载、字体页无违例、世界保存和 native 关闭。该候选仍有移动活塞、下落方块和末影龙三项注册来源保留原路径。

另一次尝试在客户端启动前被过期探针检查拦下，未运行游戏、未产生新的场景结论；后续先完成配套构建再执行。本节新增通过记录只对应所写候选，之后的末影龙与双四边形粒子改动仍待验证。
