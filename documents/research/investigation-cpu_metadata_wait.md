# 场景准备阻塞与来源维护减负

2026-11-05，承接管理员安全采集 R5 的第 4987 帧，仅进行源码修复、编译和 CPU 回归，不启动客户端或新增性能采样。创造物品栏首次打开和 GPU PT 优化不在本轮范围内。

## 问题

第 4987 帧墙钟 228.068 ms，Java 的 Native 提交占 181.322 ms，而渲染线程 CPU 增量只有 31.25 ms。留存的 Native 事件包含世界准备 176.619 ms、external-metadata 73.723 ms、metadata-init 51.306 ms、chunk-lock 41.020 ms。该片段有原生事件丢失，且原 chunk-lock 还包含取得锁后的几何和 AS 录制，不能将这些数值解释成独立、完整的锁等待证据。

JFR 的常态采样还反复命中 BlockEntityPublications 巡检、PersistentInstances 判等和 SourceBindings 历史查询。采样命中次数不等于毫秒，也不能直接相加成整帧收益。

原始记录位于 `validations/performance-sources/result/manual-deep-20261105-admin-safe-r5/`，其中 `RESULTS.md`、`analysis-combined.json`、`jfr-combined.json` 与各片段的记录共同界定本轮证据。

## 方法

沿世界准备、区段发布、诊断生产／消费及 Java 来源寿命检查锁和所有权。保留现有发布代际、完整几何、运动历史、交接、字体页失效和 GPU 在途资源退休，只移除不必要的同步及重复维护。

先按存储退役规则回收已结束、被当前记录替代的旧诊断原始包。2026-11-01 的归档先提取保留结论和分析摘要，逐条读回验证 SHA-256 后再回收；2026-11-04 的分析摘要已独立保留。当前 R5、性能基线、未结故障、输入及研究实例保持不动。

## 发现

- 诊断采集器原本让渲染线程、区块工作线程和 drain 争用同一阻塞写锁。现在使用固定容量、多生产者单消费者队列，生产者只取得容量和序号并发布完整记录；消费者只读连续完成的前缀，不等待被抢占的生产者。满队列继续显式报告丢失，现有坏样本拒收规则不变。
- 世界准备原本从 GPU 模型录制前一直持有区段锁，直到实体历史、元数据组织及上传结束。现在在锁内取得同一发布状态的静态页、外部区段、空间姿态和近远景覆盖，随后释放锁；GPU 录制及后续表组织不再占用该锁。复用既有不可变发布元数据和可重复使用的逐帧暂存容量；旧 GPU 资源仍由帧退休器持有。诊断分别标记取得锁前的等待与取得快照的工作。
- BlockEntityPublications 用当前／未出现来源链和交接／移除待处理集合代替每帧多次扫描全部所有者；可见来源捕获时直接迁移，字体批次和显式交接继续按原寿命处理。
- PersistentInstances 的身份表使用 primitive long 键；记录按机器字比较，仍逐位保留颜色、姿态和表面参数，只排除原来已排除的传输地址与局部组序号。矩阵比较直接读取各分量，保持精确位比较和 Native 接受后才登记的边界。
- SourceBindings 按视图域保存 primitive long 历史表，并复用最近域查询，避免逐绘制创建复合键和装箱；域相等语义、完整 slot 位数、来源退休／恢复和资源重载失效保持不变。

这些是源码确认的同步边和重复工作，不能据此唯一归因第 4987 帧。旧记录没有完整 C++ 阻塞栈或调度轨迹，无法还原该帧每段停顿的锁持有者、分配器和 OS 抢占占比。

## 结论

本轮消除了诊断共享写锁的等待路径，缩小了渲染与区段生产共享的临界区，并减少三处已观察到的来源维护费用。没有改变 PT 材质、几何范围、画质和来源显示规则。

存储退役共 14 个旧原始包、131.41 MiB，验证目录由 7.921 GiB 降到 7.793 GiB；逐项哈希与处理方式见 `validations/performance-sources/result/cpu-maintenance-20261105/retirement.json`。旧报告保留原文，归档摘要见同目录 `retired-20261101-profile-summaries.zip`。

CPU 回归覆盖并发写入与 drain、显式溢出、繁忙消费者、可见／未出现／删除／交接来源、字体页关闭、实例每个有效字节与字节序、历史域与重载；既有区段快照、历史及退休测试继续执行。最终命令与结果记在同目录 `RESULTS.md`。

未进行运行时或性能复测，因此不报告 FPS 收益，也不声称已经证明同类 181 ms 长停顿完全消失。下一次实际采样才可检验尾帧变化；GPU 主世界 PT 优化仍单独安排。
