# Voxy 远景光源全局索引故障

2026-10-28。修正静态区块目录与动态数组索引混用后，配套 B 包在原故障世界副本完成七阶段功能验证，无新增设备丢失，正常保存退出。人工视觉与性能仍未验收；原始失败及 GPU 转储保留。

## 问题

重做候选 A 两次进入世界约两秒后出现帧 fence `VkResult=-4`，设备故障报告包含零地址读取。用户授权用旧配套环境对照，并在定位后修正重测；设备丢失时仍须保存并停止，不自动重试。

## 方法

比较冻结 A 与 Voxy 重做前的真实源码，核对 Java／Native／GLSL 布局、场景表拼接和资源所有权。旧 Core／Extra 与 Create、Sable、航空学环境不加载 Voxy，使用同一小型世界副本、1080p、静音、旧设置 8 视距运行 90 秒后正常退出。新用例为 4 视距；这不是单变量性能或硬件排除实验。

修正只使用现有全局几何计数，不移除远景发光、完整几何或查询。复用已有静态场景测试，追加动态前缀、静态区块目录、外部后缀和 LoD 选择器的拼接检查。完成格式、完整检查、发行与严格合规，79 项 Native CPU 和 24 项 GPU 测试通过；Extra 最终 116 项测试通过。

新包与 A 的内嵌 GAME 内容不变；两套着色器 ZIP 的逻辑内容也相同，容器信息不同。变化为 Native DLL 与对应运行库索引。冻结 DLL 的 CodeView GUID／age 与 PDB 一致，实际进程加载哈希亦相同。身份见 [candidate.json](../../validations/regression-voxy_integration/result/rework-fix-20261028/candidate.json)，包对照见 [product-differences.json](../../validations/regression-voxy_integration/result/rework-fix-20261028/product-differences.json)。

## 发现

### 全局索引

`WorldPrepareContext` 临时数组不包含静态区块；上传时在动态前缀和后缀之间插入静态目录。原 `lodGeometry` 取临时材质数组长度，缺少整个静态目录的记录数。着色器却用它索引完整场景的 appearance，可能把普通区块中为零的字段解释成 LoD 表头 GPU 地址，造成非法读取。

改为同 TLAS 的 `blasAccu` 全局计数，按约定存储索引加一。零仍表示没有远景。无静态目录、存在外部区段及多节点的情况使用相同坐标系。该缺陷与已有无效地址证据一致；不把所有历史设备丢失都归到这一原因。

### 运行用例的缺口

首次修正运行不再设备丢失，但探针要求初始区具备远处才摄入的两种发光材质而中止。初始区现要求其实际存在的一种发光来源，后续仍要求至少两种。重载后还需等待完整材质和光源发布，不能仅因少量区段完成就判定就绪。两项检查均有自动反例，总运行超时未放宽。

另一次七阶段运行虽结束，但源修改前后构建数相同：修改点在客户端摄入范围外。因此未将它记为动态更新通过。最终用例修改后进入该区域，确认客户端收到海晶灯，且模型数与 Native 已记录构建均增长，再允许通过。最终 Advanced 更新为模型 11→12、构建 372→392。

通用运行器同时补齐 `VkResult=-4` 与进程退出后的最终日志检查，避免快速失败绕过轮询，回执错误地写成没有设备丢失。

### 最终运行

[最终回执](../../validations/regression-voxy_integration/result/rework-fix-20261028/functional-source-update/receipt.json)记录退出码 0、七阶段完成、无新增 GPU 转储。阶段包括初始 Vanilla PT、远处摄入、近远景返回、资源重载与旧 epoch 拒收、Advanced、真实源修改、退出重入；epoch 从 1 经 3 到 4。GPU 解码及发光表有正计数，两个截图显示实际远景内容；不将计数或截图当成全面视觉等价。

日志仍有 Voxy 来源的等待光照最终快照超时警告；本轮源修改确已到达并完成 Native 更新，尚未测量该来源等待对吞吐的影响。Advanced 截图的局部云色偏也尚未人工复核，不将其记作通过。

## 结论

全局索引缺陷已修正；相同 Extra／Voxy 和相同逻辑着色器内容下，修正后的 Native 完成原故障用例及后续功能流程，支持本次归因。它不是硬件稳定性认证，也不是长期稳定性或性能收益结论。

本轮按既有授权交付实际运行的本体、Extra 与 Voxy，Prism 操作以 [投放回执](../../validations/regression-voxy_integration/result/rework-fix-20261028/prism-deployment.json) 为准，不启动游戏、不动其他模组及存档，不提交或推送。颜色、接缝、水体、发光和动态体验继续由用户验收。
