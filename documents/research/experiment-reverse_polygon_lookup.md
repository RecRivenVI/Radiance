# 反向成对面资格查找优化

2026-10-18，接续[字体范围修复后的入队定位](experiment-font_batch_ownership.md)，只优化动态几何进入 GPU 转换前的小批次配对资格检查。保留成对薄片所有权、翘曲四边形拆分、当前成像与传光、历史及资源退休合同，不通过取消检查或减少几何提速。

## 问题

上一轮同城窗口将 `entity.queue.total` 的 12.897 ms 细分到不超过 64 个来源面的资格扫描，其中小桶为 10.500 ms。`hasReversePolygonPair` 对每个新面检查此前全部面，每对还比较循环移位；最坏 64 个面需要 2,016 次面配对比较。较大的输入已有哈希路径，不把它重新描述为全量两两比较。

检查只选择 GPU 快路或 CPU 完整处理。它不是删面，也不是相机可见性剔除；发现候选后，现有 CPU 处理仍确认配对、统一必要的拆分并写入图元策略。直接绕过会使 GPU 路径漏掉这些处理，因此不采用。

## 方法

仅替换小桶为 128 槽的栈上开放寻址表，最多插入 64 个不同键。最终位置仍按原有浮点位表示比较，保留 `normalOffset` 的采样时机、重复角点处理、有限值检查和首次命中提前返回。

每个面选择位表示最小的角点作为起点，只归一化循环移位与正反方向，同时单独保存绕序。角点相同但连接顺序不同的面不因此合并。哈希仅用于选桶，碰撞后比较完整规范化序列；对全键进行混合，避免位置浮点的相同低位集中到少数桶。正常散列下预期线性，恶意碰撞仍有有界的探测成本，不宣称最坏情况恒为线性。

小桶不初始化或访问未占用的键，也不构造大桶才需要的动态哈希容器。超过 64 面的大桶保持原有键、首成员和逆循环判定，不顺带重写其行为。不引入跨帧缓存、模型白名单、近似位置匹配、新的 GPU 同步或资源生命周期。

使用现有城市自动入口，每次恢复同一 `font-owner-comparison.zip`，SHA-256 为 `40F41782F1A065500B321C6A588B925BD5425233D741E014EBC7F8DC833B3B02`。保持 1920×1080、静音、32 视距和模拟距离、Vanilla PT／RR Balanced 等图形设置，以及保存的相机；至少预热 60 秒且队列连续平静 10 秒后采样 60 秒。两边不启动 JFR，结束后自动资源重载并正常保存退出，不访问 Prism。

## 发现

### 自动正确性

`quad_topology_test` 保留独立的旧二次扫描参考，对照返回结果、异常分类和读取顶点次数。4,612 组穷举／随机输入覆盖三角形、四边形、任意角点排列及强制全部哈希碰撞；另外覆盖空输入、63／64 面、末尾配对、重复角点、相邻浮点值、正负零、次正规数、NaN、无穷和不完整输入。原有 16 组平面／翘曲／绕序及历史检查保留。

`quad_twins_gpu_test` 在实际构建 AS 前调用生产资格检查，确认正负扭转的薄片不能误入未处理的 GPU 转换路径。实际执行的三项 GPU 测试全部通过：GPU 转换及 compute 到 BLAS、160 条面／镜像／所有者／不透明遮挡光线、48 条扭曲成对面阴影探针。没有跳过或注入设备丢失。

`spotlessApply fixMarkdown check verifyRelease verifyCompliance --strict` 通过；GAME 314、probe 34、line JNI 4、bootstrap 11 通过且 2 跳过，原生非 GPU CTest 69/69，严格合规零失败／零警告。构建日志为下述证据目录的 `pair-table-candidate-check.log`，针对性 GPU 日志为 `pair-table-targeted-gpu.log`。其余 GPU 用例未在本轮重复，不继承为本轮执行。

相机坐标／角度在两边每帧相同，雨和雷均为零，生成帧为零；实际 shader 反弹参数仍未读回，不把旧 Options 的 4 当作执行值。世界继续 tick，采样开始相差 245 个游戏 tick，配对候选计数随动态内容轻微变化；还有其他程序的 GPU 占用，记录在 `pair-table-*-load-context.jsonl`，并非严格安静的重复实验。缓存焦点字段均为 true，不当作真实 GLFW 焦点证明。仅有一次各 60 秒窗口，无长期稳定性或固定收益承诺，不将旧字体候选或上一轮 47.384 ms 窗口混入本轮收益。
