# GPU 专项优化阶段收尾

2026-11-02，本记录汇总 2026-11-01 启动的 Native GPU 专项至 SER 暂停接入。正式候选保留透明均衡采样、SHARC 修正和无用状态减负；SER、未测 AS 策略及诊断插桩不进入发行包。没有将不同负载下的两轮数字拼成累计收益，也没有完成整城、多姿态的最终性能或人工视觉验收。

## 问题

城市 32 视距、1440p 输出的初始窗口约 31.76 ms，世界 PT 约 25.67 ms，占主队列约 82%。靠近或放大水面倒影后持续低帧，不能用“四次反弹、像素数量固定”解释固定工作量；透明分支、阴影、材质处理、缓存及重建都会改变必要工作。

## 方法

使用同一 Newport City 冻结输入和水面视点，32 视距、2560×1440 输出、1485×835 内部尺寸、四次反弹、Vanilla PT／SHARC、DLSS-RR Balanced、FG 关闭、HDR 开启、POM 关闭，无 Voxy。普通半透明维持随机覆盖，不使用前景／背景混合。个人配置不自动改写。

FRAME_ONLY 记录普通帧，TIMED 独立记录阶段归因；不相加重叠 GPU 区间，不把生成帧当真实 FPS。Nsight Systems 的整卡硬件计数、软件稀疏工作量观察及普通性能窗口分开，所有故障组单独保留。正式源码与实际执行核对以[透明预算实验](experiment-transparent_budget.md)、[SHARC 执行实验](experiment-sharc_execution.md)和[路径调查](investigation-gpu_path_cost.md)为依据。

本轮整理不改变产品算法：确认正式源码没有 SER 入口，更新状态、计划及本记录，执行构建检查后投放 Prism，不启动游戏或新增性能实验。此前 GPU 合同、客户端和本轮编译分别报告。

## 发现

### 保留的产品改动及画面影响

| 改动 | 实际省去或修正的工作 | 可能看到的变化 |
| --- | --- | --- |
| 透明身份修复 | Vanilla PT 按材质 transmission 而非随机选中的 lobe 决定是否拆反射／折射，修正反射偏重、透射偏低 | 水和玻璃的反射／透射比例可能改变；是输入估计修正，不是单纯提速 |
| 均衡采样 | 首个直接成像介电事件每像素选择一路，非零选择概率限制为 25%～75%，用真实概率补偿；全反射仍确定 | 水面反射、玻璃后景和细小亮点更依赖重建，运动可能有更多噪声、模糊、拖影或闪烁；双路径保留作对照 |
| 采样分布修正 | 整数组织交错样本，匹配实际 31 位帧种子，避免极端舍入跨组与半范围分布 | 去掉中间 I 候选的分布错误，不以错误版本更低帧时作为收益 |
| SHARC 提前查询 | 实际材质、法线和介质吸收后，先查缓存，命中即复用，不再先完整求本地照明和出射 | 去掉重复相加的当前面发光与直接光，部分间接照明可能不再过亮；保留原有缓存近似，细节和响应仍需观察 |
| SHARC 训练权重 | 局部缓存辐亮度与抵达权重分开，镜面足迹使用上一散射面的粗糙度 | 水／玻璃内部吸收与不同观察距离的缓存表达可能改变，属于正确性修正 |
| 末次反弹省算 | 最后有用命中保留发光、直接光和介质处理，不准备不会被追踪的下一段 BSDF | 没有主动的画质取舍，不减少反弹上限；仍需结合其他改动验收 |
| 材质和首命中状态减负 | 次级命中不重复中转首表面 scratch；先选择手部或世界首命中，只保留最终需要的一份状态 | 没有预期画面差异；没有移除手臂查询或降低 scratch 图像容量 |

新配置默认均衡采样，已有随机路径／双路径选择保持原值。需要在 Vanilla PT 的“透明路径模式”主动选择“均衡采样”才能对比其效果。这不同于普通半透明“随机覆盖”。

共同材质和状态函数涉及 Advanced；对应代码也调整了 SHARC、训练及末次省算，但本轮城市收益数字来自 Vanilla PT，不能推广为 Advanced 已测收益。没有重写 NRD、DLSS SDK、曝光、HDR、Bloom、GUI 或 FG，也没有减少世界几何、视距、分辨率或反弹设置。

### 性能记录

透明预算最终 K 的两个参考存在外部客户端重叠和约 12.5% 自身漂移。普通帧 51.79／45.34→34.57 ms，即短 33.2%／23.7%；真实 FPS 为 19.3／22.1→28.9。独立世界 PT 为 38.03／34.42→25.90 ms。这支持减少双分支工作的方向，不能当作独占设备的精确净收益；均衡 p99 56.86 ms，相对第二参考 55.64 ms 略差。详见透明预算实验原始表格。

后续执行优化在没有其他游戏客户端重叠的同进程中，保持均衡采样，取得下列累积窗口：

| 累积候选 | 普通帧均值 ms | p95 ms | p99 ms | 最大 ms | 真实 FPS | 独立世界 PT ms |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 参考 | 22.01 | 23.56 | 26.32 | 37.74 | 45.44 | 15.88 |
| SHARC 修正 | 19.00 | 21.87 | 25.00 | 46.29 | 52.63 | 12.49 |
| 再加末次反弹省算 | 18.50 | 21.92 | 25.75 | 45.45 | 54.07 | 12.35 |
| 再加状态减负，无 SER | 18.17 | 21.72 | 24.71 | 60.13 | 55.05 | 11.73 |

这一轮累计普通帧减少 3.84 ms／17.45%，FPS 增加约 21.14%，世界 PT 减少约 4.14 ms／26.10%；p95 改善约 7.85%，但最大长帧变差。最后一次参考因随后 SER 设备丢失未完成，缓存训练、异步管线切换和时间漂移不能完整排除。末次省算与状态减负的相邻窗口差异较小，不承诺各自独立稳定收益。

初始 31.76 ms、预算 K 的 34.57 ms 与后续 18.17 ms 属于不同时间、负载和缓存窗口，不能直接拼成端到端提速百分比。没有证明任意城市视点真实 60 FPS，4K／移动／缩放也没有完成最终配套往返对照。

普通窗口整卡显存曾约 12.6→12.4 GiB，进程 private bytes 约 14.3→13.6 GiB；包含创建／退休和驱动／JIT 条件，不能宣布内存优化或泄漏修复。首表面 scratch 分配没有缩小。

### 诊断成果与未采用的尝试

Nsight Systems 已接通真实城市整卡计数；短窗口 GR 活动约 98%、SM 发射约 11.8%、RT 吞吐约 5.8%、VRAM 吞吐约 20.6%、寄存器分配约 73.3%。这些并非每个 shader 的占比，不能用空余百分比推算性能上限。

软件稀疏观察确认旧随机方式相对双路径少约 16.8%～16.9% 的已计 trace，后续 trace 少约 27%；不包含全部阴影、any-hit、SHARC 更新和 BVH 节点。手部重复 miss 没有稳定整帧成本，因此未引入屏幕裁剪系统。

Nsight Graphics 输出工具在 Qt 中崩溃，未得到可靠逐 shader stall／寄存器／spill 归因。Vulkan 管线可执行信息虽支持并启用，所查 RT 管线仍返回 0 个 executables，没有机器码证明。

NRD＋DLSS 独立启动已通过观察；RR→SR 运行中切换的矩阵警告仍是独立未闭合问题，没有靠伪造矩阵或吞日志处理。OMM、区块 AS 构建策略、深层 pass 拆分和完整 GPU 场景数据库没有实施，不列为收益。

### SER 暂停及证据

SER 从未形成可信性能窗口。城市完整着色器启用后出现 Read 页错误；Photoshop 退出和停止持续 AS 更新后仍可复现。能完成的地址构造变体约 32% 像素与无重排输出不同，不能作为正常加速候选。

普通 coherent 补丁曾完成 256 次派发且颜色一致，但后续同条件确认在第一次派发仍设备丢失，不能交付。严格 ShaderCall 可见性只做了 CPU 编译原型，未接入产品或运行。最新原始报告在 `validations/performance-sources/result/ser-coherence-confirmation/report.md`；首个故障后没有继续 GPU 操作。诊断源码、故障候选和配套符号保留，正式源码不含这些实验。

### 相邻工作区变动

专项前已完成的 Ponder RenderType 工厂精确登记、Native 元数据 CPU 暂存及 SBT 不可变身份复用仍在工作区，本轮候选一起保留。Extra 只有这项相邻适配改动，没有新增 SER 或 GPU 质量设置。它们恢复合法快速路径，保留重载、多视图及 GPU 在途版本；没有独立新的城市收益数字，也没有预期画面变化，详见[材质与提交记录](investigation-material_state_submission.md)。

诊断工具改动包括实际配置核验、显示迁移标记的正确分类和编译配置覆盖；临时原子计数、驱动验证、读回和 SER 克隆层不进入发行包。GPU 专项不等于 CPU 接管架构、Voxy 或其他第三方适配重新开发。

## 结论

正式候选保留有方向性或局部证据支持的透明预算、SHARC 及省算，暂停 SER。均衡采样具有明确噪声／重建取舍，SHARC 修正可能改变过亮的间接光，其余省算没有主动画质取舍。阶段性均值改善真实存在，尾部、移动、多姿态及最终人工体验尚未全部闭合，不以构建或计数代替它们。

本轮执行格式、CPU 检查、发行与严格合规核验，不启动 GPU 测试或客户端；最终命令结果及 Prism 新包哈希随交付汇报。人工验收重点是水面与玻璃的静止／移动反射折射、暗处和灯周围的间接照明、转头噪声与拖影。SER 不在验收开关中。不提交、不推送。
