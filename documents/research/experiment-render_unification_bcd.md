2026-10-17，按执行书 30 连续完成阶段 B、C、D。工程收敛与限定自动验证完成，最终画面交使用者统一验收；本记录不是全光栅等价、长期稳定性、性能或 GPU 根因证明。

## 问题

在保留阶段 A、字体修复、默认不透明线和已接受 adr-1 的前提下，收敛空间、目标、ABI、表面、几何与 SDK 时序。统一还必须找出多入口之间的真实差异，不能只搬动文件或通过类名宣称架构完成。

## 方法

每族先固定调查，再写合同与判别测试，逐来源迁移并保留累计检查点；不能无证据改变的外观保留并写 adr。所有测试均来自当前脏工作树，HEAD 仍为 `72d2e4a3275e782418f59142e2f2ea1f01be4120`，未改暂存区。研究记录保留首次失败、纠正与重测，未覆盖历史候选的事实。

统一采用来源无关值类型及版本适配器；原生和 shader 消费明确字段。核查范围包括普通实体、BER、粒子、区段、外部结构、Flywheel、持久模型、世界事件、手部、GUI/FBO、默认 Ponder 与结构图解的实际入口。直接世界变换、光栅投影和真实模组完整交互的验证强度分别列出，不由同一份源 ID 循环冒充全部来源实测。

### 十二组明确缺陷

1. Flywheel EPSILON／ONE_TENTH 被当作 HALF：改用固定上游实际 0.01／0.1 阈值。
2. 已知 cutout 程序被带 `solid` 的名字误导到硬件 opaque：已知来源政策先于未知名称回退，保留确有资格的 opaque 快速路径。
3. 普通、事件与刚性绘制未完整保存各自 ColorModulator：逐 draw RGBA 贯通 JNI、原生与两套 PT。
4. 来源贴图裁切发生的阶段／阈值被混作最终 opacity：按 55 个实际原版 core 程序拆出七种丢弃规则，保留覆盖率与物理透射区别。
5. 显式 endBatch 不封口，跨批次面缓存会冻结可变状态：消费者按批次封口，保存真实 setup/capture/clear 状态，原错误与恢复顺序保留。
6. 字体重载后 FontManager 的同名字体查找缓存仍指向已退休 FontSet：按实际注册对象身份使旧缓存失效，恢复原版解析；真实失败进程与修复后的运行分别保留。
7. 眼睛覆盖层合并后丢失自身 draw 色：保存独立调制，实际合成先验证所有列与资格再修改，不把 Flywheel 替色位混用。
8. 能量层遗漏来源丢弃阶段：补齐已核对的实际 shader 阶段，不擅改物理发光取舍。
9. FSR 把同一交换链 slot 再次使用的间隔当上一帧时间：三 slot 的 16ms 序列旧值为 48ms；改为每 view 单调时钟，异常值与平滑政策不变。
10. FSR dispatch 失败／初始化未就绪仍消费输出：真实返回决定成功或既有回退；FSR/XeSS 下一帧 SDK_FAILURE 重置，fatal 先传播，不录制恢复命令。
11. 保留的可选透明线把 LIGHTNING／GLINT 归为普通 ADD：复用实际 blend 适配，默认不透明不变。
12. 实际拒收报告去重集合无上限：固定 128 键及文本长度，合法绘制不增加该锁，并发回归在主线程检查全部 Future。

### 手动游玩不易发现的问题

同 RenderType 的显式封批、颜色丢弃先后、独立眼睛调色、误导性名称的硬件 opaque 资格、FSR slot 时间与失败输出，都有可判别的行为反例。它们可能只在特定透明度、同批混合或 SDK 失败时出现，不能靠一张正常截图排除。

统一过程中也发现并纠正迁移／测试问题：B2 探针反射旧类名，源阶段 GPU oracle 的错误位移，有限大法线被过强中间量检查拒绝，旧字符串/ASM 护栏仍定位被委派者，以及 Python 换行、测试构建缺失 include、独立 CMake 命令和 R: 映射问题。它们分别保留首失败与重测，不能计作已证明的设备丢失根因。

## 结论

B、C、D 工程和限定自动验证闭合，修复 12 组明确缺陷；保留差异逐族有依据。名称推断没有不加限定地“清零”：未知程序／状态组合只在版本适配器保留旧接收行为，待 adr-5；End Sea 待 adr-3；全亮物理贡献与眼睛涂层的进一步语义待 adr-6。原生和 shader 不再自行按来源名称选择上述表面政策。

最后一轮仅同步文档与交付容器检查，源码以完整快照、固定子模块及检查点清单核对，不能反推历史源码身份。合并目视清单按字体／批次、裁切／颜色／眼睛、子世界／UI／历史、SDK／屏幕效果排序，见[验收步骤](../development/testing-render_unification.md)。真实模组全部交互、所有大坐标与镜像游戏场景、所有资源包、完整光栅等价、FG 实际生成帧动态视觉、长期稳定性与性能未验。
