# 架构二期规划测量

2026-11-13，RTX 4080 SUPER 16 GB，驱动 621.14。

## 问题

记录视距容量、渲染线程和 Native 世界提交成本、JNI 首次阻塞链，以及帧线程开关对整帧和关键路径的影响。固定城市与 RTX Remix 场景，正式对照采用 2560×1440、模拟距离 12、RR Balanced。

## 方法

- 将帧间隔、渲染线程 CPU 活跃时间、Native CPU 墙钟时间、主队列 GPU 时间和显示帧率分开记录。CPU 分段可能包含等待；父子范围不能相加。
- 先保存低开销整帧窗口，再采集阶段、计数、JFR 或 Nsight 追踪窗口。FG 输出只采用实际呈现证据；SDK 未生成帧时按实际状态记录。
- JNI 顺序以串行帧内首次到达时间为依据。模拟解除某入口的阻塞只重新选择时间线中的下一个入口，保留调用顺序和实际操作。得到的是可重叠墙钟时间的上界，实际线程重叠另由运行证据给出。
- 冻结配置文件原有模拟距离为 32。已有记录缺少本轮的模拟距离 12 或含不同的实验开关，单列历史测量及其构件身份。

实际运行的产品包为 `997fada91d5a…`，Extra 为 `52a49fb65298…`，P1 整帧对照探针为 `fe74e8d679ad…`。城市与 Remix 冻结地图分别为 `598258dd1271…` 和 `d704ad369442…`，原配置压缩包分别为 `498048a97513…` 和 `777453043fd4…`。容量探针首版为 `f7a8ddec7b42…`，补上原版视距同步后的版本为 `4e38e159d484…`，两版只改变测量探针。

## 发现

### 4.1 测量基础

P1 录制入口修复后保留，默认关闭。旧探针的呈现率读取在两个 P1 开启窗口分别是 316/394、376/400 帧的首阻塞点。受影响的调用平均等待 7.70、7.97 ms。P1 关闭的两窗首先在获取帧时等待，平均约 9.12～10.01 ms。修复后呈现率读取走原子快照。探针修复、P1 收尾与工作区开关分类沿用既有记录。见[场景库实验](experiment-scene_store_upgrade.md)和[架构进度账本](ledger-architecture_upgrade.md)。

用户确认最后一次 P1 窗口有其他线程使用 GPU。该窗 35.94 ms 的整帧和 23.63 ms 的 GPU 记录排除出对照。以下涉及该窗的数据只用于追溯阻塞点及标注待复测范围。

### 4.2 视距容量曲线

只有城市 32 视距、FG 关有本轮采样。A1 的低开销窗采到 510 个帧间隔，均值 23.50 ms、P95 35.45 ms、P99 41.33 ms，渲染线程 CPU 22.29 ms，主队列 GPU 20.37 ms。进程私有内存采样峰值 16.66 GiB（9 点），进程专用显存采样峰值 6.60 GiB（2 点），整卡显存采样峰值 11.25 GiB（9 点）。Streamline／Vulkan 已接受呈现的滚动快照均值 42.08、P95 50 FPS（13 点），生成帧为零，未采集显示器扫描输出。

A1 的独立阶段窗中，GPU 世界 PT 模块 16.98 ms、RR 2.19 ms、TLAS 构建 0.364 ms。每帧约 16,840 个静态区段记录、451 次实体访问、4,162 次方块实体访问、29,982 个 TLAS 实例。源访问次数与驻留对象数采用不同口径。这组是恢复前的 32 视距直启记录。

恢复后的城市扫档实收列数为 277、565、969、1,469、2,065、3,585。FG 关闭下相应整帧均值为 13.75、18.71、20.47、21.54、22.65、24.48 ms。FG 请求开启的运行使用相同六档和实际区块数。Streamline 日志记录 `DLSS-G disabled: window not focused`，探针同时记录 GLFW 焦点为真。该运行所有测量窗的生成帧率均为零。

表中 CPU 是渲染线程活跃时间。主队列取低开销窗内完整 GPU 时间桶，PT 和 RR 取单独的阶段窗。专用显存和私有内存为进程采样峰值。SDK FPS 按每秒末次快照计算，未取得独立扫描输出。四次容量运行各一进程，视距递增。各档预热至区段队列空后取 9 秒。

### 4.7 实体常驻

已有城市 32 视距窗口中，平均每帧观察到 451 次实体访问，448 个可观测持久提交匹配。它覆盖参与持久提交的模型、姿态和外观，无法判定所有顶点可否由部件刚体变换解释。冻结存档计有 250 个展示框、198 幅画和 2 匹马，44 个展示框持有地图。前一记录未按实体 ID 把存档分类与运行计数关联。

补采的 32 视距类型窗口确认城市的 451 个已加载实体为 250 个展示框、198 幅画、2 匹马和 1 名玩家。Remix 窗口覆盖 19 个实体类型，实际采到骷髅、豹猫、展示框、兔子等来源的绘制时间。对象数与来源时间见 `phase-two-types.csv`。现有几何探针能比较部分已接管部件与原版顶点，也能记录动态提交格式。它没有为所有来源保存同两帧的逐部件原始顶点，因此本轮没有完整的刚体可解释比例或不可解释类型清单。Flywheel 的全局实例表与其他第三方来源共用，本轮表行计数无法单独归给 Flywheel。
