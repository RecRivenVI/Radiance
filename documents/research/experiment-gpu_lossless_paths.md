# 世界 PT 冗余工作优化对照

2026-11-05。A、B、C、D 合并候选在冻结城市固定视角下，主世界 PT 平均由 17.968 ms 降至 15.966 ms，减少 11.1%；未启用新的画质取舍。候选已投放 Prism，人工连续画面验收待进行。

## 问题

现有主世界 PT 中存在命中缓存前的无用材质准备、重建引导的状态复制与重复历史读取、空阴影命中阶段，以及重复材质查询和无消费者的输出写入。本轮只处理这四类工作。

不改变当前噪声和采样分布，不扩大 SHARC 的接受范围，不近似解析水波或焦散。SER 保持暂停状态，不修改 Java 来源接管、场景内容或 Extra。

## 方法

先冻结包含未提交改动的当前发行包、源码和城市输入，再一起实现四项修改。使用同一探针和配套 Extra，完成构建、图形契约及小场景回归后，只进行一组城市前后对照。

证据目录为 `validations/performance-sources/result/gpu-lossless-20261105/`：`baseline.json`、`candidate-final.json` 登记产物；`source-before.zip` 与 `source-after-overlay.zip` 登记源码，后者覆盖前者的同名文件；`inputs/identity.json` 登记冻结城市、配置、材质包、Extra 和探针；`controller-source.zip` 保留编排脚本。

城市测量采用 32 视距、2560×1440 输出、1485×835 世界分派、DLSS-RR Balanced、4 次反弹、连续光学引导、均衡透明分支、普通随机覆盖、原版云、HDR、关闭 FG，不带 Voxy。两份 SPBR 材质包保留。相机位置、朝向、时间、天气及实际生效的全部配置一致，区段队列清空后等待稳定再采样。

每个产品采一个 10 秒 TIMED 窗口。GPU 使用已有 Vulkan 时间戳，不启动硬件计数器或逐像素重探针。两次正常重载、保存退出，没有其他游戏客户端重叠、设备丢失或事件丢失。完整帧分别为 400、440，窗口内返回的主世界 GPU 帧分别为 397、437；末尾尚在途的结果不按零耗时填充。

基线为 `622c94d4f61efe4666bb286334423f5c8cb0053504bf3faaa50063fcdf315f59`，最终候选为 `539a53d1c769fb6935800fa290220efcea50b86b6106e368ad30c8fdbb4942db`，Extra 为 `47315956641c040155761f630dd85f46e701c6a582bf3f4aecd94a41eede80f2`。实际加载的 Native 核验通过，详细数据见各运行的 `analysis.json`、`loaded-core.json` 和汇总 `comparison.json`。

## 发现

### 四项实现

| 项目 | 实际处理 | 保留的边界 |
| --- | --- | --- |
| A | 不透明表面在取得相同的精确法线后先查 SHARC；命中时省去颜色、高光及叠加材质准备 | 沿用原有接受条件；未命中恢复入射权重，避免介质吸收重复；水和玻璃保留完整流程 |
| B | 重建引导直接推进已有查询状态，避免局部状态与射线载荷反复复制；历史三角形一次读取后同时计算位置和法线历史 | 未缩小公共载荷 ABI，不减少反射／折射引导，不改变历史失效条件 |
| C | 阴影确认遮挡后结束遍历，跳过空 closest-hit；不透明及镂空判定不再准备无用 RGB 染色 | 镂空、文字、半透明、物理透射及所有者过滤继续执行原判定 |
| D | 合并重复的材质标志查询和有效 UV 导数计算；停止写入没有消费者的部分输出 | 退化 UV 保留原回退；算法包内部的云、合成及后续模块都算消费者；读回、自定义包及多 PT 模块保留完整输出 |

输出图像仍分配并保留原绑定与生命周期，不宣称显存节省。写入掩码使用既有 Uniform 的空闲分量，显式刷新；没有另建场景数据库或逐帧消费者扫描。

### 自动验证与画面检查

`spotlessApply`、`check`、`verifyRelease` 通过；Native CPU 82 项、GPU 契约 29 项均通过，按实际光影参数编译的 296 个着色器请求通过。文字契约由固定三元表达式匹配改为同时检查 PBR 采样保护和中性法线初值，保留文字平面材质要求。

中间候选与基线完成相同的 14 个小场景视角，包括多层玻璃、水、发光附加层、手持物和天空；文字另由契约检查覆盖。控制场景使用原版贴图，不借此声称验证全部材质包。额外检查控制 labPBR 法线的正面和两侧掠射角。补齐 Uniform 刷新及多 PT 模块保护后的最终候选再次完成全部 7 个法线／连续介质视角。均正常退出。

已查看室内、玻璃后传送门、手持物、法线和城市的前后截图，没有发现漏画或明显材质语义变化。`surface-comparison.png`、`normal-regression.png`、`city-comparison.png` 为检查入口；随机采样、动画和历史积累使截图不逐像素相同。自动检查及静态截图不代替使用者对动态画面的验收。

主世界 PT 和世界总区间存在包含关系，不能相加。SHARC 解析算法本轮未改，即使其短窗口测值也变小，不能作为独立优化收益归因。整帧 P99 没有改善证据，不把平均值改善写成所有长帧已解决。

整卡 NVML 采样平均显存约 12116→12382 MiB；它包含其他进程与驱动驻留，不能据此认定本轮资源泄漏或几何减少。本轮没有新增长期图像或大容量缓存，也没有完成新的内存生命周期调查。

## 结论

保留四项合并修改：本次固定视角的主世界 PT 与整帧均值改善，图形契约和必要画面回归通过，三项有画质取舍的候选保持未动。不拆分本次数据推算 A、B、C、D 各自收益，也不推广成整张城市或移动路线的固定 FPS 提升。

已仅替换 Prism 本体并核对最终候选哈希，没有改其他模组、配置或存档，没有启动 Prism，也没有提交或推送。后续以使用者实际连续画面体验判断是否存在自动检查未覆盖的视觉问题。
