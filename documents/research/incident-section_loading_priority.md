# 区段加载顺序与初次来源发布

2026-10-30，使用者在 Prism 城市地图保留了大型 Sable 结构前的观察位置。本轮修正首次来源交接范围和加载优先级，形成 API 13 配套 L；功能与顺序采证通过，仍待人工连续视觉验收，不作 FPS 收益结论。

## 问题

附近地形迟迟不出现，部分远处区块却已发布；大型结构尚未显示时，其包围盒内的主世界更新也被扣住。K 的首分钟记录中，一些主世界区段版本已检测到 GPU 完成，仍等待约 10～12 秒才发布。

## 方法

复用只读冻结的 Prism 城市、配置与保存角度，在项目内以 1920×1080、静音运行；不启动或修改源 Prism 存档。输入为 `components/render_diagnostics/build/loading-order-20261030/fixture.json`，位置为 `(62.0707, 152.9629, 6.9847)`，视距 32，不带 Voxy。项目运行加载器为 21.1.259，Prism 为 21.1.265，不能宣称完整运行环境字节一致。

本体与 Extra 完成 `spotlessApply check verifyRelease` 和严格合规检查，Native 非 GPU CTest 80/80、GPU CTest 24/24 通过。交接用例覆盖装拆、分离、合并、BER／Flywheel、F3+T、作用域取消、槽位重定位、视距换代和来源卸载；随后验证同一城市的 665 个登记区段最终有 422 个内容区段可用，其余 243 个为空。

产物、DLL／PDB 与源码身份见 `components/render_diagnostics/build/loading-order-20261030/candidate-l.json`。有效运行及比较位于 `validations/conformance-takeover/result/loading-order-20261030/`：

- `candidate-l-handoff-20261030-034955`：交接回归正常退出。
- `candidate-l-saved-pose-20261030-035134`：城市加载、静止和移动后正常保存退出。
- `comparison-l.json`：首分钟发布顺序与等待记录。

## 发现

### 交接域

首次收到来源，不再无条件持有包围盒内全部主世界区段。`worldChanges` 只纳入存在已发布几何、且真实旧方块内容变化尚未发布的区段。内容版本来自实际方块状态更新，邻区到达造成的边界刷新不算转移；已发布变化和槽位旧坐标的记录不能再次形成依赖。

没有旧地形需要替换时，初次来源区段独立逐段发布。BER 与 Flywheel 按真实所有者继续交接，避免只有模型、没有地形 BLAS 的内容失去保护。明确的拆解返回世界仍收齐目标版本，包括空区段。该判定是已知待替换内容的依赖保护，不是网络操作 ID；并发的真实内容变化可能保守地形成交接。

### 排序与线程边界

普通加载先比较水平世界距离，再比较高度。玩家交互仍优先，批量交接不再借用其专用通道；强制准备的新版本即使原版仍标为 clean，也直接进入普通准备队列。公平名额按实际准入推进，不按失败尝试或每帧重新计数。Native 保留有限的久候名额，其余继续按距离选择，不将整条积压改为 FIFO。

Java 使用变换后的区段中心，空间变化只刷新仍排队成员的优先级，保留请求年龄。Native 在渲染线程把父空间和局部变换合成为排队位置快照，工作线程在原互斥边界内读取；不从后台读取可变空间表，也不以 plot 坐标对比世界相机。预算、代际、完整 PT 几何与在途退休保留。

### 卸载用例校正

首轮 L 的 `candidate-l-handoff-20261030-034315` 在旧卸载断言失败，证据保留。原测试在服务端使用 `UNLOADED`，但 Sable 的 stop-tracking 包在客户端使用 `REMOVED`，实际形成了返回世界的交接；六帧后仍等待普通版本，不等于永久依赖。

修正只涉及探针，产品 JAR 未变化：改为实际客户端 `UNLOADED`，明确断言来源 `RenderSpace` 已关闭，在六个渲染帧后才准备外部作用域，再检查完成和回调次数。新用例通过，真正覆盖关闭空间后继续使用被持有几何的边界；验证源码补充快照登记在候选清单中。旧 K 的服务器移除测试不应再被当作这个精确边界的运行证明。

## 结论

本轮已消除所复现的无关主世界交接阻塞，并统一加载距离与有限公平调度。两个有效客户端均正常退出，无设备丢失。逐圈是优先策略，并行耗时、数据到达和公平名额仍允许少量远处先完成；数据暂不可用仍等待真实输入，不能当空区段清除。完整装拆视觉与用户地图体验继续由使用者验收。
