# 降噪、超分辨率与补帧完善计划

## 目标

完善反射、折射和随机覆盖在降噪、重建及补帧中的表现，分别取得画质、实际渲染耗时和呈现证据。保留当前可运行版本作为对照，不将 SDK 升级、输入修正与参数取舍的影响混为一项。

## 范围

主力覆盖 NRD＋DLSS SR 与 DLSS-RR，实际验证 NRD＋FSR 和 NRD＋XeSS。按使用者最新决定，FG 保持关闭，不继续补帧调优；既有接通证据及未验收项保留。保留现有介质物理、第一人称、HDR 输出及 GUI 分类策略；SER 继续暂停。不提交、不推送；完成后按使用者授权直接投放 Prism，不启动游戏。

## 步骤

1. **完成**：保存原始发行包、符号、源码、配置与同内容小场景；运行时断言实际预设、参数和资源包。单层玻璃用于四次反弹对照，双层玻璃另以八次反弹检查完整光路。
2. **完成**：Streamline、DLSS、NRD 与官方 Windows FidelityFX Vulkan 组合升级；XeSS 保持已核对的最新正式版。依赖升级与输入修正分别测量，四种重建后端均已实际运行。
3. **完成本轮修复及后续分层**：相机／历史、NRD 无抖动运动、方向反射率、真实命中距离、首表面发光与去调制一致性。连续反射／透射引导可选，RR 仍单次求值；NRD 使用独立透射／覆盖背景历史。原始 PT、降噪输入输出与重建图像分别留证，不把引导查询冒充第二份照明。
4. **完成本轮自动检查**：静止、连续相机与对象运动、真实随机覆盖、Advanced、重载、尺寸及 RR→NRD＋SR／FSR／XeSS 切换。有限比较 NRD 半径与 SR 模型，未以单窗数据替换个人配置或默认质量策略。
5. **完成接通及策略检查，视觉待验收**：SDR／HDR10 均有 SDK 实际生成并呈现计数，修复插件启停的交换链生命周期；背包、局部反色、变暗及全屏模糊由真实 GUI 生产者验证。ETW 工具启动失败，显示端帧间隔、生成像素和延迟仍缺直接证据；scRGB FG 保持暂停。
6. **已交付，部分视觉已获反馈**：真实覆盖平面的分层重建、光学引导独立开关、NRD 背景材质因子及可选节点图迁移已实装，用户确认分层画面提升；移动拖影与放大成本继续收敛。默认保持普通随机覆盖与省算，见[分层调查](../research/investigation-reconstruction_layers.md)。FG 的显示端及人工验收缺口保留，后续工作暂停。
7. **完成重复工作优化，连续体验待验收**：分层覆盖复用实际背景命中，临时数据只活到所需范围；光学状态复用及背景照明缓存因成本或一致性问题撤回。1080p 全屏覆盖相对邻近旧版回测约省 13%～18% 平均帧间隔，普通视角没有普遍收益，RR 静止尾部仍波动；见[工作复用对照](../research/investigation-transparent_work_reuse.md)。
8. **有限收尾完成，不再扩展**：背景照明短期历史原型未形成实际有效复用，也没有稳定收益，已撤回临时图像、代码与开关；正式版本继续使用 C5。放大成本和残余噪点保留为限制，本轮停止优化，见[有限实验](../research/experiment-coverage_history.md)。

## 结果

当前候选位于 `versions/1.21.1-neoforge/build/candidates/reconstruction-reuse-20261103-c5/`，JAR SHA-256 为 `055eb195db28e909ba3d0fcfcffedeca302557e4db3d4dcca80b7fbf20d60751`。本轮重复工作基线为同级 `reconstruction-guides-20261103-r5/`，SHA-256 为 `0ee04cc84fa2081bc0a094821961c81e5af14fdbb0ecb4e6d9ba2d31956718b0`；前轮格栅基线 `balanced-pattern-20261102/` 继续保留。初始 SDK 基线及退役候选的源码和哈希继续保留，完整二进制按存储生命周期管理。

本轮证据位于 `validations/performance-sources/result/reconstruction-20261102/`。原始 CSV、日志和采样图像按对应索引收进 ZIP，逐文件读回校验，不因压缩丢弃原始样本。早期误标预设、未启用配置断言及带逐帧捕获日志的窗口不作为公平性能对照。旧名 `coverage` 实为物理透射的 slime 方块，不能证明随机覆盖；独立世界边界场景补查实际覆盖路径。

SDK 与输入修复阶段没有证明稳定帧率提升。后续连续引导改善输入歧义但增加查询，小场景平均帧间隔约增加 1.8～2.8 ms；覆盖分层约增加 0.37～0.83 ms，两者独立选择。RR 仍受一次加权引导的限制，NRD 独立背景历史也不等于完整多层重建，不能宣布均衡采样或所有移动拖影问题已解决。

均衡模式的后续专项将全屏重复四像素排列改为局部扰乱与跨帧分层，保持预算和重建参数。实际输入的周期验证与候选信息见[格栅调查](../research/investigation-balanced_sampling_pattern.md)；残余细噪声、共享引导导致的模糊和最终连续画面仍待用户体验，不将本次采样修正写为整套透明重建完成。
