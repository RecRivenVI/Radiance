# Voxy 远景 PT 接入计划

## 目标

以使用者指定的当前本地 Voxy 工作区及登记构建为来源权威，在 Extra 解释投影、材质与更新，Native 接收公共紧凑 LoD。保留来源已经舍弃的细节边界，复用[后端设计](../design/architecture-voxy_pt_backend.md)，不恢复全量顶点捕获。

## 范围

Voxy 与旧 MCVR 仓库只读，不重编 Voxy。保留精确近景、PT 查询语义、父子替代、历史及在途退休；不复制完整源调度器或新增 OpenGL context。不做性能实验、不提交或推送。当前按 2026-10-29 用户决定恢复：先修正模型染色合同，再以保留 Veil 改动的配套包执行七阶段功能回归；投放和人工验收以各自回执为准。

## 步骤

1. **完成输入准备**：当前 `voxy` 输入切到本地普通构建，旧输入保留为 `voxy_legacy`，版本及 SHA-256 从输入表取值。
2. **实现并通过限定功能验证**：在模型去重前保留 alpha／流体／发光及必要的染色来源；两套 PT 与 Advanced 缓存共同读取投影，修正介质进出方向，不补造完整 PBR。
3. **实现并通过限定功能验证**：去掉接收光的重建与合面差异，按实际中心／邻区版本判断快照，模型锁改为主线程非阻塞取得，过时请求合并、预算拒收结果暂存。
4. **实现并通过限定功能验证**：选中 cut 的真实发光面使用公共面积光采样，近景覆盖及父子归属与命中一致；覆盖、材质、灯光和位置历史分别判变。
5. **自动静态／合同检查通过**：本体和 Extra 的检查、发行结构、严格合规，268 个实际包配置变体，79 项非 GPU 与 24 项 GPU 合同通过；这些不能证明真实世界功能通过。
6. **修正后完成**：A 的两次设备丢失保留原证据；B 使用全局 LoD 光源索引，完成七阶段限定功能验证，真实来源修改有模型与构建进展，正常退出。按授权配套投放 Prism，不启动游戏。
7. **2026-10-29 完成限定验证**：修正含水方块继承的群系依赖与模型自身染色的混淆，保留常量色和真实群系色。当前组 `validations/regression-voxy_integration/result/tint-20261029/` 七阶段通过，代表性来源和翻译表均有实际记录，无设备丢失；历史组的停止标记不删除。配套候选已冻结并按后续授权投放 Prism，重新启用实际测试的 Voxy；没有启动游戏，视觉待验。
8. **2026-10-29 水面与运动历史完成限定验证**：使用者确认折射、光照表现合理，要求远景水共用 Radiance 动态水面，并报告走路／飞行时远景抖动。已修正来源水识别、各求值入口及同一几何的上一帧相机相对变换；当前候选实际移动 14.4 格并通过七阶段回归，无设备丢失，见[调查记录](../research/incident-voxy_motion_and_water.md)。已按后续授权投放 Prism，仅更新本体，配套 Extra 与 Voxy 核对一致，没有启动游戏，动态视觉待验。不扩大为详细远景水网格重建或性能实验。

## 结果

2026-10-29 后续体验：使用者确认抖动修复通过，水面仍有原版水颜色影响。已移除水材质中的 LoD 染色例外，使近远水体共同使用 Radiance 水光学参数，保留来源覆盖和简化几何；构建、实际包着色器及定向 GPU 通过。首次客户端早期窗口分配失败；使用者释放内存后，同一候选通过七阶段并正常退出，无设备丢失。候选与投放见[本轮记录](../research/incident-voxy_water_material.md)，不改写上一轮已保存的边界，也不宣称新水面通过人工验收。

B 的实现与限定功能验证已完成，见[索引修复记录](../research/incident-voxy_lod_selector.md)。后续解除固定几何字节上限后，用户场景出现独立的 `LOD tint index` 输入校验异常，当前修正见[染色表调查](../research/incident-voxy_tint_table.md)。当前组与 B 分别记录，不能以 B 的通过替代新包结果。A 的失败边界见[原始调查](../research/investigation-voxy_rework.md)，旧证据与停止标志不覆盖。

没有性能实验，不下收益结论。后续重点为连续移动、染色、水与玻璃、远近接缝及实际发光的用户体验；来源最终快照等待光照警告保留为后续性能调查线索。发生新的设备丢失时继续保全并停止，不自动重试。
