# 表面颜色与丢弃阶段合同

颜色调制、贴图丢弃与最终覆盖率分别表达。来源适配器登记实际程序与状态，原生和 shader 不根据内容名字猜测。此合同保持 adr-1 查询参与、世界物理线宽和默认不透明线政策。

## 来源与参数

表面政策保留普通颜色相乘、Stress 表面混合与 UV1 逆覆盖三种运算。全局 ColorModulator 在来源规定的位置应用一次：对普通材质在 UV1 覆盖之前，对 Spring 在 Stress 覆盖之前。fullbright 与发光由另一合同处理。纹理格式/目标拥有颜色传递函数；本次不增加猜测的 sRGB 转换，不把 alpha 乘入 RGB 当作预乘合成。

alpha 描述将最终 opacity 类别与丢弃规则分开：无附加丢弃、原 texel 阶段、完整调制后阶段，以及 see-through 文字的全局调制前阶段。阈值采用已核对的来源值。顶点染色强度不能当作表面透明度；普通分数覆盖、物理透射、文字及有序覆盖仍独立。

来源 alpha 描述保留 5 位最终类别，另外 3 位表达丢弃阶段；最终 GPU 材料位 20～22 保存阶段，既有位置、材质和 compact 步长不变。SourceAlpha 与 render_abi.def 定义编码；CPU/GPU 转换分别保留它，查询端只在共享函数求值。覆盖率与透射仍是不同的最终类别。

已核对的原版对象身份、Spring 与标准粒子进入明确的阶段适配；粒子不能借载体 entity RenderType 改变原始程序的丢弃顺序。任意自定义程序和未登记的程序变体保留原接收政策，受 adr-5 约束，不能据本合同宣称任意 GLSL 等价。固定加法、SRC_ALPHA 加法和 SRC_COLOR 加法仍是三种运算，不因名称相近而合并。

## 绘制封口

捕获提供者的显式 endBatch 只封口当前消费者与其状态，继续由原生完成实际绘制；不能把刷新前后的同层批次重新合并。批次保存不可变 RGBA、面与线状态，资源仍由原有提供者和纹理所有权持有。未显式封口的捕获在原有收集边界封口，异常和取消不触发提前 GPU 发布。记录不持有跨重载 ShaderInstance。

普通、世界事件和刚性模型都携带逐几何/实例的绘制参数；刚性模型仍共享不可变几何，不因颜色变化重建 BLAS。Flywheel 已有实例颜色保持独立，不重复当成 ColorModulator。

旧的按 RenderType 跨批次复用面状态已删除：同一对象的显式刷新可以合法改变状态，不能把这种变化当作复用错误。探针转到真正的 captureSnapshot 与提供者封口位置，分别保留来源归因和 setup/clear/backup/restore 子阶段；不把已封口状态在提交时再次执行回调。

普通几何每次提交额外复制 16 字节 RGBA；刚性实例记录由 136 扩展为 152 字节，带版本、步长和字节范围验证，模型与 BLAS 身份不变。该成本按几何/绘制发生，不按顶点分配，不保留 ShaderInstance，不增加 GPU 同步等待。新增全局参数只对已确认的来源程序生效；非有限来源值记录后拒收或保持单位调制，原生仍独立检查防御错误 JNI 输入。

真实封口也意味着每个批次执行一次状态回调，不再使用跨批次 RenderType 面状态缓存。这可能增加 CPU 热路径成本；本轮没有性能授权，不宣称成本可忽略或已经提速。后续若授权测量，应比较回调次数和实际耗时，再决定是否为可证明静态的来源提供纯状态适配，不能恢复会冻结动态状态的缓存。

字体查找缓存同样必须匹配当前注册的 FontSet 对象，仅字体资源名称相同不能证明提供者仍有效。查找边界验证匹配名称的缓存是否仍属于注册表，失配时恢复原版未命中解析，不绕过字形烘焙或吞掉图像错误。这会给同名字体命中增加一次注册表查找；本轮只验证所有权正确性，不宣称性能无影响。

## 来源纹理变换

已确认将 TextureMat 应用于主 UV0 的 energy_swirl 程序，在真实 setup/capture/clear 边界复制不可变的六个矩阵系数。普通实体和世界事件在 native 接管前将其应用到本批次的主 UV，保留来源 wrap 坐标，不改 glint、UV1、颜色或发光。已应用的实体记录清除变换，避免再次提交时重复烘焙；其他程序保持原路径，不能给所有材质无条件套用同一矩阵。

该来源暂不满足持久局部几何路径的外观合同，使用完整捕获回退；不冻结上一帧 UV，也不因动画修改其他来源的模型缓存。只有这个明确主 UV 变换能力退出刚性快路径，未全局关闭持久模型。非法变换在修改任何顶点前拒绝，CPU/GPU 两种 native 转换均消费同一份已变换输入；GUI 和离屏仍执行原 shader，不重复应用。

## 缓存与帧归属

Advanced 的表面缓存保存当前帧几何索引，而不丢失来源调制参数。零标签无效，正整数标签为索引加一。缓存为 RGBA32F；368 字节的实例记录与 uint32 存储范围保证索引小于 float32 的精确整数上限。解码同时核对有限、整数、绑定记录范围；无效标签不得访问 GPU 地址。

这是同帧 pass 间缓存，不是时间历史。读写者使用同一帧不可变的场景与实例参数；重载、世界切换、resize 与场景封口继续遵守既有依赖和退休。保留全部八层与现有图像格式，不增加逐像素图像、顶点步长或额外 GPU idle。

## 验证

先用真实消费者验证 endBatch 前后状态隔离、实际 PBR 编码和刚性批次，再用真实 JNI 与 GPU 求值覆盖调制、各丢弃阶段、stress/UV1 顺序、零/分数覆盖和缓存索引边界。影子比较将已证实的来源纠正与不变路径分别计数；未知程序不冒充等价。负缩放、重载和切世界的最终运行与视觉结果单独记录。
