# 普通半透明的覆盖与分层重建

两套内置 PT 通过同一属性选择普通覆盖方式。默认随机覆盖；Vanilla PT 另提供分层重建，Advanced 保持随机覆盖与前景／背景混合。来源颜色、丢弃阶段、所有者、传光与资源生命周期不随模式改变。

普通基准使用随机覆盖。分层重建只在明确选择它的专项中比较，不能把它和原有前景／背景混合作为同一模式归因。既有混合入口保留，默认与个人选择不被覆盖，见[语义决策](../reference/registry-semantic_decisions.md)。

## 接口与范围

`configs.json` 中 `render_pipeline.module.ray_tracing.attribute.coverage_mode` 唯一定义选择及默认值，生成 `RADIANCE_COVERAGE_MODE`。视频设置入口编辑当前包的同一属性，通过现有 `Pipeline.build` 重建与保存；不新增独立配置副本。外部包未声明属性时入口不可用。

只在主成像首个命中就是普通 `ALPHA_COVERAGE` 表面时开启分层。若先经过专用加法／source-over 续接，其已积累的辐射与吞吐保留原估计器，不把后一个面的 alpha 再乘到整个前缀。物理透射、cutout、文字、加法、专用不受光命中组和同物体有序表面层仍使用原有合同；传光查询仍使用随机覆盖。连续折射后的覆盖面也保留现有估计器，本轮不重写折射。

## 分层与状态

any-hit 在显式覆盖采集标记下接受非零覆盖面，closest-hit 仍按完整不透明表面计算 BSDF、照明和发光。源覆盖率单独保存在该 launch 的材质暂存 alpha，读取材质时还原接受面所需的 alpha=1；不增加 `MainRay` 大小或描述符，也不改变材质的折射率。

射线生成器保留首表面的深度、法线、运动及材质，独立复制继续直行的查询状态。在已有 TLAS 中继续寻找后方表面，每层完成原有照明路径后，在线性 HDR 空间递推：

```text
C += remaining * alpha * foreground
remaining *= 1 - alpha
```

不透明面使 remaining 精确归零，背景不再贡献；全亮的显示辐射使用同一覆盖权重，既有世界发光采样不关闭。背景支路不继承前景反射后的传光身份，保留直接成像与 UI 所有者规则。

“前景／背景混合”在首层之外最多确定混合八层；其后的尾部使用原有随机追踪完成，不能因预算清除后续几何。“分层重建”只显式拆开首层前景与完整随机背景，不再展开八层；后方的覆盖面仍正常参与。反弹数限制各层的照明路径，覆盖延续本身不消耗照明反弹预算。

Vanilla PT 的随机覆盖使用现有 FidelityFX SSSR 的 Sobol 与扰乱表，按像素、帧和覆盖层扰乱，并保留细分随机值以表达任意来源 alpha。它和反射／透射的分支选择相互独立；cutout 阈值也不因此改变。

## 合成与历史边界

前景照明、间接光和发光按首层 alpha 缩放；背景结果使用已有背景辐射通道进入降噪／合成。雾沿用原有透明表面以首表面深度合成一次的规则，不叠加第二份屏幕雾。没有世界后置光栅，也不缓存屏幕背景。

Vanilla PT 的分层重建分别生成前景与直行背景的连续引导；NRD 使用独立背景历史，RR 仍只执行一次重建，通过可选的透明前颜色辅助区分背景。具体资源与限制见[光路重建引导](mechanism-reconstruction_guides.md)。这不能为任意深层覆盖提供独立历史。

背景照明已经取得的有效终点可直接供引导使用，避免重复追踪；清晰介质和无法复用的续接继续使用独立查询。复用只改变引导的取得方式，前景和背景仍计算原有照明，不增加近似光照模式。

背景在 Advanced 使用既有次级 PT 照明路径，不另创建对应 ReSTIR 历史；原有混合仍共享首表面引导。切换通过完整管线重建重置已有时序历史，不增设全局 GPU idle 规避。快速运动、微小覆盖与透射组合仍需视觉验收。

## 验证边界

GPU 合成测试执行生产递推函数，覆盖 HDR、透明度端点、顺序、来源 alpha／丢弃、分类与非零尾部。独立真实 TLAS 用例验证两侧及镜像实例的前景／直行背景和不透明遮挡。实际 pack 入口分别编译两种模式，构建、JNI 与分发契约沿用现有完整门槛。

纯 GPU 夹具不执行完整游戏的降噪或手工 UI；真实小场景另外核对重建输入、输出与成本。自动结果和使用者连续画面验收分别记录，不由合成公式推出最终画质或性能收益。
