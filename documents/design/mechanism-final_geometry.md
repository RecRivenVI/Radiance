# 最终位置与图元历史

## 合同

最终局部位置包含来源已经烘焙的变换，以及该入口明确启用的法线偏移。`common/final_position.hpp` 是 CPU、直转准入和 GPU 的同一公式：保持 `position + 0.00001 * normalize(normal)` 的既有顺序，不把来源顶点再变换一次。未启用时不读取法线；启用时拒绝零长度或非有限源分量，不伪造方向，不提交 NaN 给 AS。有限大分量的平方和溢出但旧浮点公式仍得到有限结果时，保留旧行为，不把中间量溢出误当作新拒收条件。

偏移政策仍属于来源：TRIANGLES、QUADS 和显式索引按原条件启用；strip/fan 不增加原本没有的偏移，Flywheel polygon offset 和文字贴花也不改数值。配对发生在最终位置上，不由纹理、模型名或相机可见性决定。

## 拓扑与历史

普通与成对几何沿用已有拓扑协调器和 adr-1。历史资格先比较几何布局、数量、来源代际，再逐图元比较三个索引和拆分变体。`samePrimitiveHistory` 只收敛这个既有判定，不把 paired 位变化等同于实际对角线变化。任意来源在相同索引下偷偷重排顶点身份不能靠这个函数检测，需要来源自身的稳定身份合同。

两套 PT 的八个历史读取共用判定，当前和上一帧缓冲仍由原在途所有者保留。没有增加全局等待、历史索引副本或每顶点动态分配。

## 验证

CPU 旧公式精确对照、零/非有限法线拒绝，以及 GPU 对同索引、交换索引和拆分变体的判别共同锁定边界。既有成对面、条带、fan、线模式和实际 Java CPU/GPU 对照继续执行。完整画面与动态历史由最终运行及目视分别确认。
