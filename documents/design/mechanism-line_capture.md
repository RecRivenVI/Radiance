# 显式线请求与姿态接管

阶段 A 仅统一底层的 LINES、LINE_STRIP、DEBUG_LINES、DEBUG_LINE_STRIP。模型框、绳索本体、光束和其他面图元不因此改成线。工程实现不改变[成像与传光决策](adr-1-query_visibility.md)。

## 分层

`render.contract.LineContract` 只包含 JDK 类型：来源、绘制空间、帧戳、线样式、顶点布局和提交状态。Minecraft 的 RenderType、Pose、加载器事件和第三方类只出现在适配器。`LineSources` 显式登记入口；身份用于追溯与历史，不按类名或内容名前缀猜测线语义。

```text
来源 renderer / 事件
→ Storage 或 WorldLineCapture 复制端点、RGBA、切线和绘制基底
→ LineDrawAdapter 解释来源线宽及混合状态
→ 版本化描述符与现有实体 / 世界帧载体
→ JNI 同步解码并展开棱柱
→ 原有上传、BLAS、TLAS、帧发布与退休
```

普通实体、BER、Sable、Simulated 拉杆/绳索、Create highlight/世界事件和 Veil 事件使用同一线描述符。原始回调不重放，不缓存上帧最终顶点。来源变化和不允许连续合并的 strip 各有独立捕获批次；表面缓冲继续走自己的路径。

## 空间与宽度

端点在捕获时应用绘制矩阵一次；矩阵方向随顶点复制。原生按 Y 参考正交化 X，保留镜像奇偶，只用所得基底决定截面绕轴。无姿态的标量输入明确使用 owner 基底回退。大坐标的场景原点继续由既有 double 坐标载体传递，不从最终 float 端点反推。

切线 normal 与可选的截面参考是不同字段。派生模型轮廓显式提供参考，原生不再根据 `contentName` 改变 normal 含义。Sable 的线包装器在默认标量转发前保留矩阵；非线输入仍执行原有包装语义。

世界物理厚度政策不变：普通线每来源单位 0.005 方块，调试线 0.0075 方块。来源线宽缺省为 2.5 时，分别为 0.0125 与 0.01875 方块。来源明确声明的宽度及自定义状态实际设置的宽度不再被整批参数覆盖。原版空宽度 shard 的窗口像素放大继续折回名义值，避免把已取消的像素政策重新引入世界厚度。

混合状态明确区分不混合、覆盖率、加法与破坏性调制，保留端点真实 RGBA。按[不透明决策](adr-4-world_line_opacity.md)，世界线描述符默认选择 `OPAQUE` 有效材质，原始颜色和 alpha 字节不改写；两端均零 alpha 的连接段仍不展开。调试自发光、普通材质与 priority 身份保留各自含义，不统一其他材质族。

来源透明实现保持可用：显式设置 JVM 参数 `-Dradiance.lines.sourceAlpha=true` 时，世界线改选 `SOURCE_ALPHA`，使用真实来源的 alpha 模式与端点 alpha。开关在启动时读取，不增加默认配置或界面选项；默认不设置。该路径与不透明路径共用捕获、JNI 和几何展开，均参加回归；屏幕光栅与模型框不经过此选择。

## 生命周期与权限

世界事件线拥有独立缓冲；正常 endBatch 只排空自己的线。未显式排空的线在原生产阶段封口前收齐，不对其他类型执行全局 endBatch；异常或取消时丢弃本阶段的自有缓冲。JNI 返回前已完成线解码，临时描述符和 Java 缓冲不进入异步 GPU 引用。GPU 资源继续按原有完成条件退休。

帧、世界、资源代际和阶段仍由 WorldMeshSink 与 native 校验。线批次来源布局改变时，相关实体不复用不兼容的上一帧位置；不含线的实体保持原有历史规则。

世界后置权限见 [adr-2](adr-2-world_raster_permissions.md)。Veil 的固定缓冲排空仍发生在生产阶段，后处理单独延期；未知 listener 执行一次原回调，不自动获得后置光栅权限。GUI、相机覆盖和离屏目标不受此权限一刀切影响。

## ABI 与诊断

每条捕获顶点 72 字节：位置 0、RGBA 12、打包切线 16、绘制基底 20/32/44、可选参考 56、参考标志 68。每几何描述符 64 字节：magic/version/source/flags 位于 0/4/8/12，物理厚度与来源宽度 16/20，owner 基底 24，自发光 60。alpha 模式与 owner 镜像位编码在 flags。查询身份、模式和帧戳沿既有载体传递；其取值由合同决定，不重复推断。

更改参数布局的 JNI 使用新入口名，旧 DLL 无法误绑定新参数。生产解码器与无设备 JNI 回归共享实现；Java 捕获夹具另外交给原生截面测试。

`radiance.lines.audit=true` 启用固定来源表的影子/不变式计数，默认关闭。比较来源厚度与旧批次厚度，差异归类为修复；显式参考替代名称约定，事件接收替代旧拒收。不会逐顶点输出日志。每顶点增加 16 字节输入，每绘制增加描述符和状态采集；没有进行性能测量，不能声称开销不可测。自动验证与目视清单见[线条回归](../../validations/regression-line_capture/validation.md)和[当前计划](../project/plan-render_unification.md)。
