# 有序重合表面层

同一实体的已知来源程序，若按顺序绘制同一表面的底色和附加层，原生侧将其表达为一个几何界面上的有序材质集合。普通装饰不获得额外发光；来源全亮层保留物理辐射并参与世界照明。

## 来源与资格

资格由实际附加层能力和 shader 身份共同确定，覆盖监守者、旋风人眼睛、项圈、铁傀儡裂纹、马匹花纹和盔甲材质／纹饰。混合／自定义顶点语义、非白全局 RGB 与受击／闪烁 overlay 的组合、未知程序、自定义混合、EQUAL 深度 decal、物理透射及文字不推断为 source-over；本轮覆盖已知 LEQUAL 的不透明／裁切／普通覆盖路径。加法眼睛继续使用独立的眼睛涂层合同，与 source-over 不混合。

需要完整底层和部分模型层的所有者使用普通完整捕获；原 renderer、动画、部件选择和回调继续执行。末影龙的独立 renderer 也保留眼睛合成所需的完整捕获。混合加法眼睛与普通装饰的自定义所有者沿既有加法路径，不宣称获得通用有序层支持。

## 几何与颜色

在最终位置偏移和拓扑准备之后，仅匹配同一次对象提交内位置逐位一致、绕序一致的三角形，允许循环移位。不同对象、反向薄片、近似重合和不同所有权不合并；同一界面存在不支持的操作、不同面规则或薄片归属时，该界面的全部来源保持原路径，不跨过未知／EQUAL 等操作合成两侧的已知层。底层可见面必须覆盖附加层可见面；保留薄片成员的独立面归属。

同一物理三角形保留一个 AS 界面，各层保存独立 UV、纹理、顶点颜色、全局调色、alpha、PBR 属性和发光。只移除已经转入材质集合的重复 AS 图元，不丢弃其绘制内容，不挪动表面。部分模型和不同 atlas UV 不要求完整模型或 UV 相同。

source-over 按后绘制层到先绘制层选择材质，权重为该层覆盖率乘以上方各层的未覆盖率。使用已有 PT 覆盖采样策略的随机表达，长期期望保留原合成顺序；单个样本不承诺与光栅混色 RGB 一致，也不将多种 PBR 参数线性混合。每个候选层先按自己的 UV、LOD 和来源丢弃阶段计算覆盖率。选择后避免再次随机裁切。

AH 与 CH 从同一帧、光线起点／方向、几何和图元身份取得一致选择；不消耗可变路径 RNG 来决定已经接受的材质。阴影和次级路径使用同一材质集合；发光不限定到主相机。

## 所有权、历史与边界

每个本帧 Entity 持有不可变材质集合缓冲与逐图元范围，按现有重要上传队列提交，随 Entity、历史和在途帧保活。不引入全局 idle、可覆盖的共享缓冲或常驻无界缓存。场景重载仍走原资源代际和纹理退休。

布局身份记录附加层归属、来源顺序和重复图元移除。归属改变时拒绝旧位置历史；只有 UV、颜色或动画 alpha 变化不改变拓扑身份。保留底层 glint 涂层，不把普通纹饰变成发光。

此合同不覆盖任意 GLSL、多种自定义混合或不能确认的近似表面。自动 GPU 覆盖采样接缝、CPU 生产助手和 shader 编译分别验证各自层级，不能替代实际动画、细纹饰和时序噪声的目视验收。
