# 成像、传光与几何参与规则

## 状态

已接受

使用者于 2026-10-15 确认下表及水面处理；接受决策不代表实现或视觉验收已经完成。

## 背景

自身模型、手部、优先级内容与水面目前使用分散的掩码和射线状态。跳数不能表达连续折射后的观察者身份，摄像机隐藏也不能通过降低不透明材质的 alpha 实现。

## 决策

| 几何类别 | 直接成像，包括连续折射 | 优先级成像 | 接受世界照明 | 影响世界传光 |
| --- | --- | --- | --- | --- |
| 一般世界几何 | 显示 | 否 | 是 | 是 |
| 第一人称自身模型 | 隐藏 | 否 | 是 | 是 |
| 第一人称手臂、手持物 | 显示 | 否 | 是 | 否 |
| 轮廓、名称牌、锁定标记 | 隐藏 | 是 | 是 | 是 |
| 单向几何的不可见面 | 隐藏 | 否 | 是 | 是 |
| 船内实际水面 | 隐藏 | 否 | 否 | 否 |

第一人称手部指摄像机专用表示。世界实体中的手臂与持物仍属于世界模型。摄像机脱离、睡眠等来源可见状态保留来源语义。

直接成像从相机开始，穿过覆盖率透明、薄片透明或连续折射时保持身份。反射或漫反射后进入传光查询，之后的折射不恢复直接成像身份。阴影与光照采样始终属于传光查询。

优先级成像替代对应几何的直接成像，不能额外叠加一份；它不自动改变材质、发光或传光参与。来源面状态与绕序继续捕获，直接成像使用来源面规则，传光使用双面材质响应。重合反向成员仍按薄片所有权选取一次界面。

2026-10-17 验收补充：第一人称自身模型对摄像机隐藏的要求，同样约束该模型的自身发光效果／轮廓的优先级表示，不能通过优先级通道重新显示自身。其他实体的优先级显示及自身模型的世界传光参与不因此取消。首次验收失败保留，后续[集中修复](../research/investigation-query_visibility_repairs.md)的实现和验收分别记录。

手部可以接收遮挡、照明与环境反射，但不向世界投影、不成为世界反射命中或光源候选、不把手部结果写入公共光照缓存。屏幕覆盖仍由屏幕效果阶段管理。粒子等按一般世界几何处理；名称牌按表中的优先级通道处理。它们只在生产时面向摄像机，不为每条查询重新转向。

船内水面使用来源船内遮罩定义的局部排除关系：越过该层几何的船内水面不成像、不传光。不能把它扩张为沿射线无限忽略所有水，也不能把删除控制遮罩误写成删除实际水面。来源范围必须准确，船外水面保留。

水面只排除数值自命中。按离开界面的几何朝向与浮点精度偏移起点，不设置材料级豁免；不同水面、真实入水与出水边界、多层界面及再次合法返回同一表面的命中必须保留。

## 后果

可见性判定由查询用途、几何通道与来源属性共同决定，不再以首跳判断代替用途。不可见交点不贡献颜色、吸收或成像深度；几何仍留在传光场景。该成像例外不等于改变材质透明度。

自动验证必须区分直接、连续折射、反射后折射与阴影；覆盖手部仅接收影响、优先级不叠加、成对薄片与合法多层水面。构建、GPU 自动测试与真实视觉验收分别记录在[项目现状](../project/status-current.md)。本次不修改或追溯改写旧研究记录。
