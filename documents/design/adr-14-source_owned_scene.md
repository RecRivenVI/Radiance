# 来源维护的持久场景与通用执行平台

## 状态

已接受

使用者于 2026-10-25 批准本轮架构与实施，并已确认安静环境可用。配套实现、自动回归与项目内客户端对照完成，结果及边界见[本轮实验](../research/experiment-source_owned_scene.md)；人工外观仍待验收。

## 背景

129 修复巨大 Sable 结构的空区段饥饿，但主世界和外部区段仍分别调度。模型与实例已驻留，来源仍会重复建立本帧绑定与参数，然后在提交末端比较；Sable 逐帧收集成员，Flywheel 父 embedding 的变化使成员全部标脏。

## 决策

Vanilla 与 Extra 解释来源并维护内容、成员和变化；Java 公共平台统一资源、实例、区段、空间与所有权；Native 保存已接受版本并执行现有渲染。Flywheel 是来源，不作为公共平台的依赖。

区段统一请求、版本、准备、编译、预算、完成发布和退休；已知空、暂不可用与卸载明确区分。来源只提供数据与依赖，不建立平行执行系统。交互优先与后台公平性继续存在。

成员引用共同空间，区分内容、姿态、外观、资源和成员关系变化。来源已经插值的姿态直接消费；端点插值只接受明确的来源规则，不重复插值。世界平移保留双精度，历史按实际视图与上一帧资源记录。

可靠版本或事件使昂贵准备提前失效或跳过；确实变化的动画、瞬时几何和必要回调继续执行。通用捕获是明确的生产方式，不用上一帧最终顶点冻结未知来源。来源语义状态、待提交变化与 Native 执行记录各有唯一责任。

保留现有查询、材质、完整几何、GPU 完成条件及退休机制。不改变 GUI／FG、启动、LOD 取舍和画质，不以本轮强制建立完整 GPU 场景数据库。

2026-10-26 使用者补充明确：这里保留的是几何和材质意图，不是光栅最终着色。Vanilla／Extra 在世界输入中排除运行时 AO、固定面向明暗和 lightmap 对颜色的调制，保留真实材质颜色与显式物理发光；满亮数值不能单独推导发光。GUI／预览保持自身光栅表达。来源判变同步排除这些无效照明参数，实际影响几何、染色和光源的依赖仍更新。

## 后果

本体与 Extra 需要配套升级公共接口；使用现有世界／资源代际拒绝过期内容。成员空间可减少 Java 重复生产与传输，但最终成员变换、TLAS 及视图派生仍有成本，不承诺其复杂度全部成为只随变化增长。

本轮以 129 的完整城市、配置和模组副本作配对基线，使用 32 视距、1920×1080、静音及原画质。接口版本由 `render_abi.def` 定义，本体与 Extra 配套更新。不提交、不推送、不自动投放 Prism；129 的源码、产物和证据保持冻结。
