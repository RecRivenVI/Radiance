# 表面材质合同

表面政策在来源适配器解析一次，消费者读取独立的 alpha、颜色运算、法线和捕获能力。合同本身不引用 Minecraft、加载器或第三方类型。来源的透明 shard、shader 身份、实例字段与自定义程序由各适配器负责，不能把全亮、颜色覆盖或执行组当作透明分类。

## 输入与执行

普通材质、弹簧专用来源政策与模型刚性准入共用同一政策记录。普通颜色相乘与表面覆盖染色分开；alpha 编码来自共同整数表，不依赖 enum 序号。世界查询所有权继续由 adr-1 及原有提交通道决定，不由 alpha 决定。

原版适配器保留 RenderType 的实际状态与文字协议。Flywheel 适配器精确登记其 OFF、EPSILON、ONE_TENTH、HALF shader；未知 cutout 程序的现有接收方式按 adr-5 保留，不能将它计作已精确适配；改变其拒收行为须先获决定。遮罩阈值由共享求值决定；覆盖率保持分数值，介质透射、加法与乘法层分别保留。

GUI 与离屏光栅仍执行原 shader，不强制降为 PT 材质。Ponder PT 不恢复。普通世界事件、实体、实例化的材质可以有不同执行组，但相同字段含义和阈值必须一致。

## 验证边界

旧/新分类的影子向量保留固定旧值；确认的 Flywheel 阈值纠正独立标注。实际 Java 顶点、跨语言源布局与 GPU 求值共同验证字段，不能以源码搜索代替。资源重载继续让既有材质/模型消费者失效；合同记录不另建持久缓存，不改纹理代际或 GPU 退休条件。
