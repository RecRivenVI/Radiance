# 渲染平台公共接入

平台版本的唯一来源为 `render_abi.def` 的 `PLATFORM_API_VERSION`。本体、Extra 与 Native 必须使用配套构件；这不是跨代兼容承诺。接口供当前 Target 的渲染线程使用，除明确允许后台准备的入口外，不从其他线程访问渲染状态。

## 来源与资源

`SourceIntegration` 接收来源回调，`WorldScene`、`RigidScene`、`LodScene`、`GuiFrame` 接收通用输入。第三方图层名、源程序名及对象资格由 Extra 解释，平台只接收有序覆盖、不透明／source-over、离屏保留等语义。没有适配器时不凭名称猜测。

`Spatial.sleepingPose` 和 `nameOrientation` 在原版对应求值位置提供来源空间修正，不接管整个 renderer。`Raster.supportsStaticState` 检查本次图层是否可使用声明状态；额外状态无法证明可省略时返回 false，仍执行原路径。Extra 对固定字节的来源修改登记审阅证据，同时核对运行时追加项，不能仅凭 Mixin 名称整体放行。

`RenderResources.Buffer` 拥有持久缓冲身份，声明用途、初始化容量并上传范围；Native 在 JNI 返回前复制借用的 CPU 数据。替换与关闭交给已有帧退休机制。`RenderResources.Texture` 拥有 RGBA8 或 `scalarField` 的 R32F 图像和代际，限定尺寸、mip 与上传区域；关闭后不能再次使用。Voxy 投影页和 Sable 持久缓冲使用这些入口，不访问 Native 对象或设备地址。

现有 Minecraft／Veil 互操作接口不因包名包含 `client` 而重写。下列成熟能力正式作为当前版本的接入面；新增通用资源优先使用上面的所有权对象。

| 能力 | 支持入口与责任 |
| --- | --- |
| 既有纹理名、上传所有权与源 atlas 通知 | `TextureProxy` 的创建、存储、采样、上传、绑定和释放；`TextureTasks.Owner`、`TASKS.owner/use/useAll` 保证代际检查和实际使用处于同一临界区。借用者不释放他人的纹理，不直接改 `TextureTracker` 的映射 |
| 纹理描述 | `TextureProxy.imageMetadata` 返回不可变记录；`attachmentMetadata` 登记通过 framebuffer 接口创建、仍有所有者的附件。源 atlas 回调中的 CPU 地址只在调用期间有效，保留者必须复制 |
| Veil 顶点数组、缓冲和程序 | `VertexArrayProxy`、`BufferProxy`、`ShaderProxy` 的分配、配置、提交和释放接口；数值 ID 是引擎句柄，上传地址只指向本次借用的 CPU 内存。创建方成对释放；不导出 Vulkan 对象或设备地址 |
| 离屏与既有绘制状态 | `FramebufferProxy`、`PipelineStateProxy` 的附件、读写目标、状态和合成操作；调用方恢复借用的状态，遵守世界／GUI／离屏边界 |
| 能力查询 | `RendererProxy.tessellationSupported/backendString/capabilityLimit`；不把查询结果当作任意 GLSL 支持 |
| 区段与现有捕获 | `SectionScene` 声明来源成员与局部位置；`ChunkProxy.enqueueExternalRebuild` 接收实际内容失效。`EntityProxy` 的变换实体、方块实体和线条提交仍保留完整捕获。共用调度、版本、容量、完成发布和退休，不直接修改平台队列或槽位 |

`api.render.internal`、其 JNI、可变 tracker 映射以及代理类中未列为接入能力的实现状态均不是扩展接口。Extra 不维护平台状态的第二份权威副本；来源必要的 CPU 镜像不等于 Native 资源所有权。

## 空间、成员与变化

`RenderSpace` 是当前世界内的来源所有者，保存局部双精度姿态、法线基与可选光照空间，父空间不能形成环。`pose` 接收来源已完成插值的最终姿态，Sable 使用此模式，不在 Native 再插值。显式选择 `motion(before, after, start, end, time)` 的来源使用 `PoseEndpoint` 平移／单位四元数／缩放端点；`sample(time)` 只推进来源时间。四元数走最短弧，平移和同号非零缩放线性插值，时间钳制到端点；拒绝非有限值、非法区间及穿越奇异缩放。它不是任意矩阵线性混合。再次 `pose` 结束端点模式。

Java 保存提交端点与时间，Native 保存执行版本并按父依赖组合；无关空间的更新不使该成员缓存失效。后台来源可以更新 Java 姿态；句柄发布、帧刷新及关闭在渲染线程执行。成员及子空间先关闭，父空间随后关闭；世界关闭使旧 Java 身份失效，Native 不复用旧世界的数值身份。

`sectionColourGradient(x,y,z,offset,r,g,b)` 为区段成员声明世界空间的标量平面，钳制到 0～1 后，将来源顶点 RGB 混向目标颜色。透明度、法线和发光强度不变，普通实体／独立实例不继承。父空间可提供默认值，`clearSectionColourGradient` 移除当前覆盖。Native 按区段当前的绝对姿态将平面变换到局部坐标，公共顶点材质在纹理相乘前求值；移动或旋转不重新编译区段。来源业务和目标颜色由 Extra 决定。

`LayeredWorldMaterial` 拥有材质身份，借用已登记的基础、细节、深度、强度和调色纹理。输入为有限的分层投影／世界水平薄层参数，包括 UV 动画、深度范围、软衰减和明确的总发光量；不是任意 shader 解释器。依赖纹理过期即失效，重载后由来源重建。可见求值和面积光采样使用同一深度／强度遮罩与透明度。加法薄层不引入介质，也不消耗散射反弹次数；必须严格沿查询方向前进。

水平薄层的 `planes` 接收 double 的 X/Z 原点；原点高位放在 `origin.xz`，低位放在该程序的 `motion.zw`，不改变 112 字节布局。遮罩、采样与命中 PDF 使用同一相机相对空间；世界纹理相位在转换为 float 前按实际采样器的 repeat／mirrored-repeat 周期归约，clamp 保留边界语义。纹理地址模式变化使材质映射快照失效。

区段材质流可使用精确字典：材质地址最低位为编码标志，去除该位后为 16 字节头（调色表偏移的 uint32 字数、顶点数、条目数、保留），之后为逐顶点 uint32 索引和 16 字节对齐的完整 80 字节记录。仅在至少节省四分之一空间时启用，其余仍直接存储。着色器统一使用 `loadMaterialVertex`／`loadTriangleMaterial`，不能把带标志地址直接解释为顶点数组。顶点位置、拓扑、材质位模式、发布所有权与资源退休不变；不保留额外的 CPU 驻留字典。

`SourceHooks.invalidateSectionShape` 将方块位置归一到区段原点后通知形状依赖，不要求已存在 `RenderSection`。原版方块更新和区段失效均接入此通知；没有通知的第三方可变形状仍须由对应来源声明变化。

`SectionScene` 只维护成员及固定局部锚点。成员增删或重定位时同步变化；普通帧检查平台区段代际，重置后重绑。空间版本变化只刷新仍在排队的成员优先级，不重新生产几何或重置请求年龄。主世界与外部区段进入同一个请求队列、准入／快照、编译和预算流程，来源未到达不清除有效旧几何。平台准备版本与 Minecraft 的 dirty 标志分开，已有 compiled 数据不能使新绑定漏编译。

局部模型通过 `LocalModelBatch.selectUnchanged` 先检查已接受的来源状态，再决定是否准备绑定、组名和参数包；真实变化或驻留被拒仍走完整提交。纹理的实际使用仍受所有者临界区保护，不因复用而跳过。`RenderSpace.Placement` 使已捕获的父基变换回到局部实例表示，完整捕获的消费者保持原世界变换；同一父姿态不会重复作用。

Native 保存空间和实例记录，按实际视图组合最终变换并保持上一帧结果。当前接口不接受未知来源的任意插值规则、不建立完整 GPU 场景数据库，也不免除动画求值或瞬时几何生成。

## 局部来源属性

`SourceBindings` 由实际实体、方块实体、粒子或破坏进度对象持有，保存稳定定义、绑定与分域历史身份；资源重载按代际惰性失效。`VanillaPoseMemo` 保留每个来源自己的部件树与姿态快照，采样公开动画字段、可见性和成员变化后只重组受影响节点。原动画数学、事件和材质回调仍执行，不能让共享模型中下一对象的状态覆盖上一对象。

`LocalSurface` 将统一的来源颜色、light、overlay 和 UV 仿射与局部网格分离，和全局 draw modulation 分开保存。不同层／面的真实差异仍保留在绑定或几何中，不能拿一个统一颜色或 UV 覆盖全模型。绑定携带各层 UV；变化绑定仍可能形成新资源，不能将这些路径记成零更新。

`LocalGeometry.submit` 接收来源拥有的不可变局部模板与独立姿态、`LocalSurface`。模板键随实际几何变化，不能把可变模型仅按 renderer 类当作稳定资源；纹理代际、材质策略与资源重载继续参与失效。定义只在缓存未命中时展开，不读取上一帧最终顶点。消费者不支持时返回 false 且不触碰消费者，适配器继续原始生产；光栅预览不进入此入口。

`LocalGeometry.supported` 在生产局部几何前检查本次消费者与姿态资格，不保证缓存容量或后续准入。`release(key)` 退休该身份的缓存定义；同帧已提交视图保留不可变 CPU 字节，Native 按原有帧资源所有权保留在途版本。连续形变只替换当前定义，不能保留所有历史形状充当动画缓存。

`LocalModelBatch` 独占借用有界暂存，`records()` 返回精确范围的只读借用视图，重置或关闭后不得继续使用。归还时清除来源与纹理引用，超出池容量的存储直接释放；Native 同步消费借用包，接受后才更新持久状态快照。来源不能修改已接受快照或因复用省略纹理有效性检查。

`BlockEntityPublications` 保留普通 BER 最近一次可消费发布，供明确的来源交接使用。`SourceIntegration.Spatial.blockSource` 提供空间所有者，未加入交接的删除不会留下可见副本。交接收齐目标 BER 后，与 `SectionHandoff` 同步释放旧版本和开放新版本；正常动画继续求值，本帧未求值才补交已保留版本。字体页退休先撤销旧文字批次与驻留选择，重载和世界关闭释放全部发布。该租约不把任意动态 BER 声明为不可变模型。

局部请求独立声明 WORLD、CAMERA、CAMERA_SHIFT，和世界／第一人称／嵌套粒子的历史域分别管理。第一人称沿用手部状态和使用动作计算，将手臂、袖层、物品和地图叶子接入资源请求；嵌套粒子以粒子作为来源所有者。非均匀仿射只有在来源法线矩阵与相应逆转置一致时直接实例化；无法表达的消费者或法线继续精确执行，不猜测替代。

世界方块请求使用实际位置、种子、模型数据、邻域几何遮挡和染色。原版 AO、固定面向明暗及 lightmap 不进入 PT 基础色；在对应光栅计算入口跳过，不以除去已混合明暗的方式恢复颜色。缓存记录真正影响模型和材质的查询，并在复用前重新采样；自定义模型确实用亮度决定几何时仍维护该依赖。标准 JSON 的简单／加权／multipart 模型图经过来源资格检查；未知子模型和不可追踪的可变内部数据保留原细分。破坏阶段与贴花投影独立于方块主体。

`Geometry.bulkConsumer` 接收实际用途 `pathTraced`；来源可去掉只为光栅照明服务的包装。Extra 据此在世界保留 Sable 原始面法线，预览继续使用其方向光模拟，不能将两种用途合并为全局替换。

世界文字按来源保留布局、字形页与有序层资源，位置、颜色和覆盖作为实例参数；字体页换代、文本／样式变化使其重建，混淆文字仍实时求值。不是每个字符增加一个 TLAS 实例，也不改变 GUI 字体光栅路径。

世界输入的 packed light 在来源适配入口归零，不参与稳定定义或绑定判变。UV2 满亮本身不代表发光；已审阅的粒子发光方法在排除基础环境采样后表达来源 glow，眼睛、发光附加层等沿用显式发光政策。纹理／生物群系／染料颜色、逐层 alpha、受击覆盖与 glint 保留。`RasterPreviewScope` 保留预览原有 AO、lightmap 和面向明暗，预览不复用世界未受光定义。

来源在批次已选中实例之后被删除时，删除结束后续驻留，本批次仍使用已采样版本，并将模型引用交给已有帧退休机制。若同批次提供新参数，则以新版本替换；不变选择不能使已删除实例复活。Java 批次持有选中来源直至原生提交结束，弱引用回收不能提前退休该版本。

## 效果计划

`ScreenEffects.Plan` 明确阶段、临时目标尺寸、按序 pass 和最终输出。输入 0 是提交时的画面，临时目标从 1 编号；只能读取已经产生、且不与当前输出重叠的目标。每个 pass 指定自己的输入、NEAREST／LINEAR 和四个有限浮点参数；最终回写的缩放另由 `outputSampling` 指定。目标尺寸为输出尺寸的正整数分频，向上取整；最多八个目标、三输入和三十二个 pass。

程序为现有内置 kernel，或 `SpirvProgram` 持有的编译后 Vulkan fragment SPIR-V；不是 GLSL 自动翻译器。Native 在建立 shader 前用已有第三方源码中的 SPIRV-Reflect 核对：单个 fragment `main`、location 0 的 `vec2` 输入和 `vec4` 输出、set 0 的 binding 1／2／4 的一至三个 `sampler2D`，以及可选的十六字节 fragment push constants。拒绝额外资源、存储／设备地址能力和不匹配的接口；输入须为合法编译器产物，反射不代替完整 SPIR-V 语义验证。

Native 实际将声明的图像及采样方式绑定到每个 pass，按目标尺寸执行后发布指定结果。程序、pipeline、图像和 descriptor 的在途引用保留到既有帧完成边界；descriptor 在对应帧上下文重新可用后复用。`SpirvProgram.close()` 在渲染线程调用，已关闭定义不可提交；Native 模块重建后，仍持有的定义按新代际重新注册。

`WORLD_POST` 在世界后处理完成后更新 FG 的无 UI 输入；`GUI_POST` 保持 GUI 路径；`FULLSCREEN_MENU_BLUR` 继续标记全屏模糊并按既定政策禁用 FG。它们不授权把世界后置光栅混入 PT，也不改变 GUI／FG 决策。现有蜘蛛、苦力怕、反色和菜单模糊均通过这个计划入口，图解的专用合成保留原本必要的程序。

## 世界环境输入

平台版本以本文开头的唯一来源为准，旧 Extra 会被版本检查拒绝，必须使用配套构件。

`LocalModel` 接收来源明确声明不可变的局部四边形定义，由 `Instance` 维持独立历史与寿命；位置和父空间改变不重新展开顶点。来源负责模型、材质、染色、模型数据和资源重载的失效，未知动态模型不得仅按类名缓存。

`RenderResources.immutableBlockModel` 复用当前原版适配器对完整烘焙模型图及实际加载变换的资格判断，不能视为任意第三方模型的不可变声明。`blockTintEmission` 提供与实际染色同步采样的来源发光值，不含原版受光。

`SectionHandoff` 在渲染线程收集 `SectionScene`、主世界区段及 `Participant`，`seal` 后以 `tryCommit` 等待当前请求版本完成几何或确认变空，再共同发布。重叠与显式 `join` 的交接共享门槛；旧几何按现有帧资源退休。主世界候选重新请求当前内容，不能用转移前已发布版本充当就绪。局部实例必须在提交交接之后选择本帧版本，不能由后台回调独立切换。关闭是取消／清理，不是成功完成的证明。

来源先收齐交接依赖，再由已封闭的 `SectionHandoff.tryCommit` 刷新区段完成结果，随后检查当前版本是否就绪；不能在来源注册持有之前提前发布。多个作用域共享活动世界帧的一次刷新，没有待交接时不增加该调用。Java 编译准入仍在来源回调之后回收其间完成的新工作并独立采样积压，保留 Java／Native 转移的保守计数，不缓存跨回调或嵌套视图可能失效的预算。既有信号量等待与资源退休不变，不增加阻塞等待。

`worldChanges` 用于首次发现来源：只持有已经发布几何且存在尚未发布的实际方块移除版本的主世界区段，返回是否找到这样的旧内容，不制造额外重编译。移除记录来自真实方块状态更新，邻区到达导致的边界刷新不算转移，已发布移除也不影响后续刷新；槽位重定位清除记录。没有旧地形需要替换时，初次来源区段可以逐段发布；普通 BER 与 Flywheel 仍按实际所有者保留交接。`world` 用于明确的返回世界操作，继续收齐目标版本（包括空区段）。两者都不将批量交接升级为玩家交互优先级。

Java 与 Native 普通加载采用相同的世界空间区段中心与相机区段，先比较水平距离，再比较高度；玩家交互优先，久候后台请求占有限的公平名额。Native 由渲染线程为排队区段准备空间位置，工作线程只读取锁内快照，不访问可变空间表。并行完成、数据到达和公平名额允许少量远处先完成，不承诺严格的逐圈显示顺序。

交接按每个收集作用域登记区段依赖。取消只解除该作用域的持有，共享成员继续等待其他持有者；仅失去最后持有者的区段恢复普通版本检查与发布，不将其他作用域标为完成。槽位重定位只移除该旧坐标的依赖，不能提前结束整个交接组。来源卸载时，仍被其他交接持有的区段保存最后的组合姿态与区段染色，随实际区段退休；不继续保留活的来源或接受关闭空间的新提交。

`cancelled()` 区分取消与成功，平台区段代际改变后旧作用域自动取消，不把旧 token 送入新世界。适配器应重新收集仍然存在的来源。`SectionScene` 持有前重新建立当前代际的绑定；外部区段未绑定时不能按同值数字索引持有主世界槽位。`waitingReason()` 按需返回来源参与者或原生区段版本的等待摘要；持续等待 15 秒后记录日志，此后最多每 30 秒记录一次，不据此强制发布。

确认空区段也是当前版本完成，必须通知 Native；尚未到达的数据不是空。编译失败保留既有几何与当前请求版本，记录原因并按 250 毫秒至 30 秒退避重试，新的内容版本可以立即推进。失败重试不调用来源内容变化钩子制造新版本，也不将失败标成已准备。

参与者提供 `ready`、`publish` 与 `cancel`。`seal` 结束收集；只有所有参与者准备好后才封闭 Native 门槛。调用方先对所有关联交接执行 `prepareCommit`，再逐一 `tryCommit`，最后共同选择局部表示；不能在第一个未就绪项处提前返回而遗漏其他关联项。成功回调只执行一次，取消不证明替代内容就绪。来源负责在等待期间保留其模型、实例和父空间，并在发布回调中交换实例；Native 仍沿现有有序上传／BLAS／TLAS 和帧退休路径执行，不引入全局 GPU idle。

`WorldView` 的 `fadeStart/fadeEnd` 是直接成像及连续折射的随机截止范围，不是空气或流体吸收。`atmosphereColor` 是来源解释完成的线性天空颜色（主世界为中性参考比值）；`environmentFlags` 当前保留为零。`SourceIntegration.World.imagingDistance` 只声明更远成像覆盖半径，不能删去传光几何，也不写 OpenGL 雾状态。SkyUBO 保持 96 字节，新增雷暴强度使用原保留字；摄像机浸没分类仍供真实介质使用。

Vanilla 从原始群系雾色采样和资源包天空纹理提供颜色，Native 不调用 Minecraft 雾计算。具体产品差异见[环境决定](../design/adr-15-environment_and_imaging_fade.md)。

## 紧凑远景

`LodScene` 接收区段节点、紧凑矩形、投影模型与染色表。格式版本及字段常量取自 `render_abi.def`，224 字节模型的 `material.z` 高位保存显式 alpha 类型；普通半透明不自动变成折射。Java 解释来源，Native 不识别方块名称或 Voxy 私有位布局。

已选节点的发光面采用来源投影和染色进行面积光采样，位置、纹理和覆盖归属与实际命中一致。灯光索引保留对应节点，跟随模型及 cut 变化；不复制近景的光源候选。Native 计数前七项依次为驻留节点、选中节点、模型数、驻留几何字节、已记录构建、发光面、发光组。字节数不包括所有图像、表、在途旧版本或整卡显存。

后续三项为有效非空 PT 节点、完整近景覆盖节点及主世界覆盖修订。`coverage(previousRevision)` 在修订不变时返回 null，否则提供当前主世界覆盖的不可变 RLE 快照；保留的交接几何不是新的近景发布。适配器可据此暂停被完整覆盖区域的细化，边界或未完成区段仍保留原逐命中判断。不同来源不能把暂不可用的数据当空区段。Native 的有效节点与发光表共同排除完整覆盖项，快照和缓冲由既有在途引用保持。

覆盖、材质与灯光分别失效，未变化的近景覆盖可被新 header 复用。场景追加阶段将当前视图首个 LOD 几何索引加一写入 UBO 的 `lodGeometry`；零表示没有远景。这是 Native 派生数据，Java 初值为零，多视图仍使用各自实际场景。帧引用持有 header、材质、覆盖与光源节点至执行完成。

## 保留区段与颜色场

`SectionMeshes.retained()` 在渲染线程接收已发布、已由来源声明保留的特殊图层，只读 BLOCK 格式局部四边形携带区段、原点和发布身份。适配器接受完整发布身份，但发布变化不等于内容变化：新发布的原点、数量与全部来源内容相同时，可以继续复用模型并记录已接受版本；真实变化须先建立替代项。未出现在下一次集合中的成员必须移除，不能用旧区段编号判断仍然有效。它复用原有离屏保留副本，不保留整张世界的第二份几何。

`WorldScene.submitDeformingQuads` 接收已解释的 PBR 四边形与稳定动态身份，复用固定四边形索引模式及已有动态运动历史、帧代际和退休路径。坐标是显式双精度原点加局部浮点位置，CPU 输入在调用返回前复制；不得把变化网格声明为不变的刚性模型。它没有承诺持久化动态 BLAS 或免除位置上传。

`LayeredWorldMaterial.colourField` 提供纹理与来源颜色相乘后的 HSV 色相、饱和度／明度指数，以及两个可选减色项。来源的噪声和物理参数仍由 Extra 解释。可选 R32F 场每个顶点占相邻两个像素：噪声幅值与减色权重。图元内先按重心插值，再取指数；不把贴图颜色的非线性运算简化为固定 RGB 乘数。

PBR 输入的 `glintUV` 指向第一个像素，`glintTexture` 为 `COLOUR_FIELD_MATERIAL_BIT | material.owner().id()`，不启用 glint、覆盖层或顶点 BRDF 法线。此显式标志避免普通顶点的未使用字段误命中材质程序。Advanced 主／次级表面缓存使用对应的无覆盖通道保存完整浮点场值，直接光、反射及连续折射继续使用相同材质；既有真实顶点法线通道保持独立。

`quadColourField()` 将颜色细分与实际几何分开：每个来源四边形保存 5×5 个节点，每节点仍占相邻两个 R32F 像素。`glintUV` 是四个角点的单位方形坐标，`glintTexture` 的低 12 位是材质所有者，随后 19 位为四边形编号，最高位为显式颜色场标志。命中时按原 4×4 单元及其拆分对角线插值，再执行相同 HSV 运算。保持几何及基础属性插值等价的前提是平面平行四边形、仿射 UV 和基础颜色；不将翘曲面的曲率替换成平面。

## 来源计算表面

区块材质地址可能携带字典标记，算法包必须通过本体当前 `loadMaterialVertex`／`loadTriangleMaterial` 公共着色器读取，不能继续按未标记的 80 字节直接数组解释所有地址。此为当前 Native 材质 ABI，外部包若自带旧读取实现需同步更新；加载器不协商旧布局。

`ComputedSurface` 接收来源已解释、已编译的受限 SPIR-V 与不可变输入，属于世界几何和字段生产，不执行任意 Veil 绘制程序。创建与提交限定于有效默认世界 stage；资源和 stage 必须同代。`SourceIntegration.World.sectionInvalidated` 在任何空间适配器消费区段变化之前通知观察者，用于失效局部派生数据，不改变区段所有权。

固定计算 ABI：`main`、工作组 64×1×1、单一 set 0，push constant 为四个 uint：首个调用、输出顶点偏移、输出索引偏移、总调用数。绑定 0／1 是只读来源数据／参数，2／3／4 是输出位置／材质／索引，5 是只读辅助数据，6 是二维采样图，7 是 R32F 存储图。位置与材质布局沿用 `shared.hpp`；索引相对本几何起点。来源程序负责与声明范围一致的边界检查，以及位置、属性和拓扑的正确性；Native 核对反射 ABI、资源类型、尺寸及代际。

零顶点和零索引表示只更新字段；几何输出走现有动态批次的 GPU 转换、BLAS、历史与帧退休，不经过 Java 最终顶点展开。输入只上传一次，参数在调用返回前复制。输出材质使用的纹理和材质所有者须通过 `materialImages` 声明，与噪声和字段目标一起原子校验代际。每次分发独立持有参数、输入、程序、纹理及描述符，不原地覆盖在途几何；关闭句柄只禁止未来引用。字段写入与所有前序读取有序，写后在加速结构构建和追踪前可见。此接口不承诺动态 BLAS 持久更新，也不豁免输出缓冲和 AS 的真实成本。
