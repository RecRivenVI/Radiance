# 阶段 A 线条目视验收

本清单适用于 Minecraft 1.21.1 NeoForge 的阶段 A 候选。构建、CPU/JNI/GPU 合同、隔离运行与目视结果分开记录；使用者此前通过的拉杆旋转和主菜单淡入仅属于原候选范围。本阶段不做性能测试，也不重启 Ponder PT。

## 候选与入口

最终源码、发行 JAR/DLL、自动结果和检查点由[统一计划](../project/plan-render_unification.md)登记。未经明确投放授权，不操作 Prism。自动实例的准备与启动见[线条验证](../../validations/regression-line_capture/validation.md)，不是要求使用者执行的性能实验。

本轮机器用例已通过：原始拉杆/绳索 emitter、Sable 包装器和 NeoForge/Veil 事件线，混合宽度/颜色、镜像与非均匀缩放、快速转动、取消、resize、资源重载、保存退出和重进。该用例不是本表的逐项目视通过，完整的 Create 交互和实际旋转结构仍需观察。失败与重测证据见[验证研究](../research/experiment-line_unification_validation.md)。

## 连续观察清单

2026-10-17 使用者连续观察后反馈线条总体良好，但 F3+T 触发字体纹理异常。新的字体生命周期候选沿用线条语义；优先完成下述重载复测，再按需继续原矩阵。不要求重复全部已观察场景，也不将概括反馈代填逐项通过。

随后使用者确认字体修复候选 `D3402E12…` 的 F3+T 已修复，并决定世界线默认不透明。新默认按 [adr-4](../design/adr-4-world_line_opacity.md)执行，来源透明路径保留为显式入口；下表按默认模式验收，不要求恢复分数透明度。原候选的重载通过不代替新默认包的完整验收。

1. 进入测试世界，让聊天中同时保留中文、英文和不同样式文字；打开聊天确认正常，关闭输入框后按一次 F3+T。
2. 等待重载完成，重新查看聊天、物品提示和菜单文字。不得崩溃、乱码、缺字或把旧 UV 映射到新图集；界面中的其他内容和线条仍应正常。
3. 确认正常后可再重载一次，观察聊天文字跨重载是否保持一致；有材质包时再切换实际使用的包。保存退出由使用者操作，日志与身份由 Agent 核对。

不启动游戏的自动回归及其边界见[字体生命周期修复](../research/experiment-font_texture_lifecycle.md)。实际材质包组合和目视结果不由 CPU 接缝测试替代。

| 场景 | 操作 | 应看到什么 / 失败判据 |
| --- | --- | --- |
| 普通世界 | 对方块、实体开启选中框、F3+B/F3+G，切换视角 | 位置与原请求一致，来源颜色和宽度有区别；不得重复出线、漏线或将调试框永久盖在所有内容之上 |
| Sable 与活动拉杆 | 转动物理结构、操作油门拉杆，绕结构移动相机 | 外框与活动部件保持相对姿态；不得额外绕线轴滚动、漂移或重复应用结构变换 |
| 绳索外框 | 悬停多段弯曲绳索，移动两端或旋转宿主 | 外框持续随原来源端点变化，线段不透明，零 alpha 连接分隔仍不出线；绳索本体模型保持原行为 |
| Create | 观察普通/曲线轨道选择及链式输送机交互 | 真正的线请求可见且位置正确；Catnip 模型框保持原模型，不能被二次转换或多画一层 |
| NeoForge / Veil | 打开粒子或 BER 边界调试、已安装的 Veil 编辑器线视图 | 原始触发条件生效后才出现；同步与延迟排空均不漏线，不能靠后置世界光栅掩盖拒收 |
| 混合样式 | 同时观察粗细不同、来源 alpha 不同及渐变颜色的线 | 默认均不透明，各绘制保留自己的物理厚度与 RGB；隐藏连接不应复活，不要求三维棱柱等同原版像素抗锯齿 |
| 屏幕 / 离屏 | 打开菜单、F3 调试准星，进入水下、打开结构图解 | 屏幕效果和离屏画面照常存在，不因 WORLD_RASTER 允许名单丢失；不得把 UI 线投到世界里 |
| 历史与重载 | 快速转动相机、resize、F3+T、退出测试世界再重开 | 无长期残影、旧来源线混入新帧、宽度意外缩放或 stale 缓冲被再次提交 |
| 成像规则 | 第一人称、自体调试框、发光轮廓、反射与折射 | 继续符合 [adr-1](../design/adr-1-query_visibility.md)，不因线条统一改变所属通道 |

自然设备丢失时停止当前用例，保全本轮日志，不自动重启或反复尝试。画面不符时记录场景与操作，机器日志和候选身份由执行 Agent 读取。未知 GPU 根因、长期稳定性与公开二进制许可仍独立保留。
