# 安装与使用

适用于 Minecraft 1.21.1 NeoForge。你可以用 Radiance 替换世界渲染，并在受支持的 GPU 上使用路径追踪、DLSS 等功能。

## 安装

当前验收使用 NeoForge 21.1.259。既有版本声明下限为 21.1.62，其他版本尚未按本轮完整绘制巡检重新核销。将完整外层发行 JAR 放进你的实例 `mods/`；GAME 开发构件不能单独安装。当前完整包仅供本地验收，公开二进制许可仍未确认。

## 材质与兼容

PBR 材质包可直接加载。Create、Sable、Create Aeronautics、Veil 及内嵌模块使用 Target 元数据的固定兼容版本；Zume 不在兼容版本限制中。未安装这些可选模组仍可运行。

## Voxy 远景

可选的 Voxy 接入使用已适配的 NeoForge 1.21.1 本地版本 `0.2.20-beta+1.21.1-neoforge`，仍需另行安装 Voxy。Radiance 使用其存储、模型代理和 LOD 网格进行世界路径追踪，不启动 Voxy 的 OpenGL 远景渲染器，也不额外安装 Sodium。

目前适配内建 Vanilla PT 与 Advanced；选择其他着色器包时远景会暂停，近景继续正常渲染。远景发光可通过实际命中与间接传光影响世界，Advanced 的远景光源重要性采样尚未接通；雾距离已映射，但不保证与 Voxy 原光栅淡出逐像素一致。

先探索一片区域，再返回观察近景范围外的缓存地形；未被 Voxy 摄入的区域不会凭空出现。远景保留 Voxy 有意简化的形状、静态纹理、材质和精度，精确近景继续使用原有模型和材质包。远景水沿用代理几何，不恢复源后端没有保留的原版波动。

本候选的自动功能检查与视觉验收分别记录，尚未完成使用者远景画面验收；本轮不测性能，不承诺帧率提升。检查近远景交接、树叶、玻璃、水、发光代理以及 F3+T 后的画面，发现破面、重复、残留或空洞时保留日志。

## 成像与照明

第一人称身体不会出现在直接画面及连续折射中，但仍参与世界的反射、遮挡与照明。摄像机专用手臂和手持物保持可见、可受光，不向世界投影或出现在世界反射里。

单面材质的背面在直接画面及连续折射中隐藏，反射、间接光与阴影仍按双面材质处理。轮廓、名称牌和锁定标记由优先级画面显示，同时保留世界受光与传光；第一人称自身的轮廓同样对摄像机隐藏。船内水面按来源盖片与实际船底之间的范围隐藏，船外水面保持原有作用。

## DLSS 帧生成与界面

启用 DLSS 帧生成后，有效世界背景上的背包、聊天及仅压暗的暂停／设置界面可以使用补帧；暂停仍停止游戏模拟。实际执行全屏菜单背景模糊、加载覆盖、世界背景被替换或输入未准备好时停止补帧，条件恢复后自动恢复，不改变保存的开关。该策略已取得实际生成帧与启停证据，人工视觉验收尚未进行，后续补做。

整屏压暗作为背景颜色处理，不把没有控件的地方标成界面覆盖；已有 HUD 仍按原顺序被压暗，按钮、文字与三维预览保留原透明度和层次。全屏模糊依据实际绘制调用识别，不因设置中开启模糊就始终停用。

准星保留原版反色，物品、文字和界面层顺序不变。界面重组仍可能处理界面动画，不代表全部界面绕过补帧；生成帧的动态外观需在受支持的设备和实际启用状态下观察。

## 普通半透明

视频设置的“普通半透明”提供“随机覆盖（现有模式）”和“前景／背景混合”。现有模式保持默认；选择后按“应用”，重建完成才生效。设置随当前着色器包保存，Vanilla PT 与 Advanced 均提供此项；不支持的外部着色器包会禁用该入口。

混合模式将普通半透明表面的受光颜色与实际追踪的后方场景按来源透明度混合。它不是水或玻璃的折射开关，不改 cutout、文字、加法附加层及专用不受光绘制的规则；世界线条仍按不透明决策处理。背景也由路径追踪取得，不是屏幕截图。

新模式已获定向视觉验收通过，但使用者报告部分半透明叠加明显卡顿，正在与多光源、高视距问题一起调查，尚无性能改善结论。多层结果仍共用最近表面的深度与运动历史，经过折射后遇到的普通半透明、以及超过分层预算的部分继续使用原有随机采样；其他组合与长期动态表现不能由合成公式代替视觉验收。

## 已知边界

室内站立与下蹲应保持连续的照明，不应仅因姿态切换发生整幅色调与帧率突变；自身在画面中的隐藏不改变它对世界传光的参与。区段重新编译时，告示牌等方块实体不应闪失，资源重载仍保留必要的旧资源退休保护。这些修复的新候选等待本轮目视复核。

满足条件的普通烘焙模型现在复用局部几何，并继续更新每次绘制的姿态与外观；不支持的自定义模型、附加层和变形保持原有捕获路径。此优化不降低视距、动画频率或反射／阴影中的几何覆盖，也不保证所有场景取得相同帧率收益。

物品展示框中已由资源管理器发布的稳定模型进一步复用烘焙资源，热帧只更新姿态与实际外观。模型选择、物品颜色和附加效果保持原规则；资源包重载、模型替换或不支持的自定义绘制不会被上一帧内容冻结。新的自动样板结果与使用者画面验收分开记录。

原版实体和方块实体的稳定局部部件也会共享几何；每个对象的动画、可见部件、装备和颜色继续按当前状态更新。眼睛、盔甲和不支持的消费者保持其原有合成。其他模组改动这些来源时，未经核验的部分会退回完整绘制，不以缓存上一帧画面代替变化。

原版四边形粒子同样共享基础面，每帧仍更新位置、朝向、旋转、尺寸、贴图、颜色和透明度。自定义模型粒子继续运行原有绘制；资源重载和切换世界会清理旧资源，不冻结上一帧的粒子。

原版绘画也会在生成规则稳定时复用完整网格，保留背面、厚度、逐格照明和资源包贴图更新。其他模组改写绘画生成或使用特殊绘制方式时继续完整生成；本轮自动核对不代替你对实际画面的观察。

主菜单首按钮闪白、旋转拉杆轮廓及随后修复的红色加载页过渡均已获定向目视通过；启动到主菜单仍有长时间未响应的独立反馈，正在定位。线条统一的阶段 A/B 已获本轮定向目视反馈，尚未观察的第三方组合不因此标为通过。正常的按钮悬停高亮会保留。

世界线条采用三维物理厚度并默认不透明，各绘制的宽度和 RGB 颜色独立保留。屏幕准星、离屏画面及 Create 模型框仍保持各自的绘制规则。

船只等实体使用原版的帧间朝向插值，避免转向只在游戏 tick 更新时跳变。此修复不更改操控、船桨动画或网络更新频率；船只运动、加测矿车、船桨及船内水面剔除已获定向目视通过，不代表全部载具或网络条件均已验证。

渲染统一候选保留逐次绘制的颜色、裁切阶段与独立发光层，修正 Flywheel 的来源裁切阈值。资源重载也会校验字体缓存的实际所有者，避免读取已经退休的字体集。FSR 使用当前视图的连续帧时间，升频失败时显示合法回退结果并重置历史；这些自动检查仍需结合实际画面验收。

眼睛层修复候选保留蜘蛛红眼、末影人紫眼及其世界照明贡献，充能苦力怕电弧的纹理应随时间滚动。全亮几何必须实际照亮其他世界几何，不只显示发光或 bloom；这项产品选择不等于原版所有不受光绘制都会自动变成光源。上述眼睛与动态附加层已获本轮目视通过；末影人眼睛向头颅内轻微照明仍保留独立边界。 旋风人的风层沿原动画滚动；监守者发光纹理、普通项圈／花纹／裂纹和盔甲纹饰按来源颜色及覆盖顺序绘制，普通装饰不因覆盖处理自动发光。普通装饰与覆盖顺序以及随后可切换半透明的定向视觉均已获通过，不扩大为所有组合或性能通过。

F3+T 的字体图集与文字批次生命周期已作定向修复，并获得本次手工重载通过反馈。随后收窄了字体批次登记范围，减少实体密集场景中的相关周期性停顿；重载保护保持有效，其他卡顿仍在调查。实体较多的场景还减少了成对表面的检查开销；该优化不改变材质、遮挡或动画规则。该反馈不代表所有材质包组合或长期运行已验证；重载后仍应保留聊天内容并正确重绘字形。

不变场景复用已准备的着色数据，保留完整几何、材质与重载行为；短时城市测试已有性能改善观察，不保证所有场景取得相同比例。

区块加载的共享锁争用已有定向修复，保留相同几何与画质。本轮世界加载对照因设备丢失中止，尚不能保证所有加载卡顿均已消除。

历史设备丢失根因、长期稳定性与部分视觉专项未全部闭合。请在测试前备份世界。构建与 GPU 合同通过不能替代你对实际画面的验收。
