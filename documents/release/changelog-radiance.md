## [未发布]

适用于 Minecraft 1.21.1 / NeoForge。

### 修复

- SHARC 命中后直接复用缓存光照，避免重复叠加当前表面发光与直接光；保留介质吸收并修正缓存训练权重。省去末次反弹不会使用的出射准备和次级命中的首表面材质中转，既有配置不变。
- Vanilla PT 按材质身份选择透明双路径，避免由随机选中的折射分支决定是否拆分而重复计入反射；新增均衡采样模式，保留透明反射／折射的概率补偿，已有个人选择不变。
- 场景表复用录制上下文的 CPU 暂存容量，未变化的命中组序列复用解析结果和 SBT 内容身份；保留多视图隔离、重载失效、完整几何、运动历史及 GPU 在途资源退休。
- HDR 界面默认跟随所在显示器的系统 SDR 参考白，避免开启 HDR 时界面突然变暗；保留手动调节，Bloom 默认强度降至 3%。
- 统一两套内建 PT 中材质发光的直接可见、反射、折射与光源采样强度，修正光源代理读取纹理的红蓝顺序和线性颜色。
- 区段编译与 Native 准入共用含高度的空间距离带，同带内按来源轮转，避免巨型结构仅凭任务数量挤占主世界；超大区段排空限定在最近距离带，保留交互优先与远处就绪工作推进。
- 区段槽位换到新坐标时清除原版与 Radiance 的旧交互优先级及排队记录，避免普通远处区段继承旧位置的放挖优先权。
- 区块材质逐字节无损去重，减少高视距及持续移动后的显存压力；不减少几何、不量化颜色、法线或 UV，非重复内容继续使用直接存储。
- 程序薄层保留水平原点精度，并在相机相对空间计算遮罩；重复纹理先规约周期，避免远坐标 End Sea 投影丢失位置精度。需配套 Extra。
- 方块变化独立通知来源的区段形状缓存，补齐尚未建立渲染区段对象和负坐标空间的失效路径。
- 区段放置或破坏方块时，已发布的来源表面保留到替代快照完整就绪，避免水晶短暂消失；移除最后一层来源表面和确认空区段时仍正确退休。
- 为来源提供受限 GPU 表面计算与四边形虚拟颜色细分，避免为了动态颜色扩张稳定几何；计算输出继续遵守世界代际、运动历史和在途资源退休。
- 为来源适配提供已发布特殊区段面的只读访问、通用 HSV 颜色场与动态四边形提交，保留世界 PT、运动历史和帧资源退休；需配套 Extra。
- 已建立交接保护后、判定区段版本就绪前回收已完成构建，避免 GPU 已完成的更新因帧内检查顺序额外等待下一帧；准入仍在来源回调后读取最新积压。
- 区块普通加载统一按世界空间距离向外推进，公平调度不再将积压全部改成先入先出；批量交接不冒用玩家交互优先级。首次发现来源只保留实际待替换的旧地形，避免大型结构未显示时无关主世界区段一起等待。
- 区段交接按实际持有者取消，共享成员和槽位重定位不再提前放行整组；被保留区段在来源卸载后保持最后姿态与染色，重载后重新核对绑定所有者。
- 区段编译失败保留已发布几何，记录具体原因并退避重试；持续等待的交接记录缺少的版本，避免将失败伪装为空或无声地每帧重复失败。
- 已确认的主世界空区段也会完成交接版本，修正命令生成的大型 Sable 结构因等待空气区段而一直不显示的问题；保留共同发布与资源退休保护。
- 静态区段复用已发布的加速结构实例记录，简化未变化目录的场景表复制计划，并复用公共实例批次暂存集合；保留相机精度、动画、材质换代与在途资源退休。
- 小型长期图像与普通设备缓冲使用较小分配块，减少退出世界后的空闲显存驻留；加速结构存储保留原分配方式，预算查询按设备实际支持启用。
- 公共持久实例提交复用有界暂存与已接受快照；光束将 UV 滚动和颜色独立于稳定形状。远景复用未变化的选择及派生数据，完整近景覆盖时不重复参与世界追踪，保留交接、光源与运动历史。
- 内置掉落物经过路由或轮廓输出时保留原消费者链，避免错误强转存储所有者而崩溃。
- Voxy 静态远景保留上一帧的相机相对变换，避免走路或飞行时向降噪／超分提交错误运动历史；几何换代仍使旧历史失效。
- Voxy 水面接入 Radiance 既有动态水面和共同水材质，避免烘焙的原版水颜色继续影响光学颜色；保留来源覆盖与简化几何，Advanced 的首次命中和缓存求值使用相同水身份及动态水面设置。
- 移除 Voxy 远景几何的固定 256 MiB 驻留限制，保留用量统计、节点与在途任务限制及资源退休，供大场景验收。
- 重做远景代理的来源材质、染色、更新和物理光源接入，修正静态区块与远景共存时的光源索引错误；需配套更新本体与 Extra，实际外观仍待验收。
- 公共局部模板允许适配器复用来源已声明稳定的几何，并独立更新姿态与外观；普通方块实体发布可参与区段交接，保留重载、字体页和在途资源保护。
- 结构交接门槛可以等待来源实例准备并共同发布，保留区段、局部模型与 Flywheel 的配套交接和资源寿命。
- 为结构来源提供共享局部模型与区段交接能力；主世界和外部区段等待当前替代版本完成后共同发布，保留旧资源的在途寿命。
- 修正 labPBR 法线在掠射角被压成与视线相切、导致不透明表面全黑的问题；两套内建 PT 共用修正，保留真实几何遮挡和原有材质参数，不添加亮度下限。
- 恢复末地传送门与折跃门的原版投影和逐层颜色累加，不与 End Sea 共用亮度归一化。
- 修正虚拟球形地面对下半天空日月的裁切；真实方块遮挡继续有效。
- 保留物理透射材质的退出边界，避免玻璃后的 End Sea、天空与其他表面受到错误的长距离介质吸收。
- 恢复原版无世界界面与加载覆盖层的 60 FPS 限制，世界内帧率设置不变。
- 世界 PT 使用同帧发布的程序材质与遮罩参数，避免 End Sea 遮罩跟随摄像机时短暂错位。
- 末地／下界的加法前景光按自身距离参与雾合成，避免近处 End Sea 薄层被无限远背景雾覆盖；保留后方场景的正常雾。
- 移除玩家低于地平线时的黑色下半天空及最低高度附近的雾色压黑；保留正常雾、失明、黑暗状态与真实环境照明。
- 统一八位来源颜色解释，修正发光鱿鱼墨粒子颜色编码引起的异常亮度，保留真实发光。
- 将原版云接到共享表面光照并保留完整必要几何；补齐世界边界全亮意图，区分覆盖透明与介质透射。
- 跟踪连续介质的进入、离开、吸收及两侧折射率，保留来源粗糙度；第一人称相机几何只影响自身照明范围。
- 日月贴图、照明方向与可调倾角共用变换，月相影响实际月光；天气参与大气传输，不添加环境亮度下限。
- 支持有明确纹理、软遮罩和能量参数的世界薄层；配套 Extra 保留 End Sea 的空间形态与结构渐变染色。
- 连续中心测光和 EV 曝光适应替代硬边区域与线性亮度适应，保留已有色调映射和个人设置。
- 启动复用未变化的着色器包提取结果，按真实依赖筛选编译定义；早期窗口 CPU 信息不再同步查询系统处理器负载。
- 渲染准备期间继续使用同一加载窗口、动画和真实阶段进度，准备完成后再启用世界管线；完整介质历史留在光路推进阶段，避免命中载荷反复传递整套历史。
- 禁用视差的表面复用普通材质、光照与介质处理，保留独立的禁用视差能力；逐字节相同的着色器模块和管线阶段复用，材质命中组保持不变。
- 将荧光墨囊文字的明确全亮状态传为物理发光，普通文字与告示牌主体保持受光，光栅预览不变。
- 世界 PT 材质不再预先混入原版环境遮蔽、固定面向明暗和 lightmap；保留贴图、染色、受击覆盖和显式物理发光，GUI／物品预览继续使用原光栅照明。环境光数值不再触发局部模型、文字或绘画的无效资源重建。
- 将地图、第一人称动作、末影龙特殊状态、嵌套模型粒子、破坏覆盖和世界文字接到共同来源请求；稳定结构、绑定和布局提前复用，动画与必要算法仍实时执行。增加显式端点姿态插值，来源已插值的最终姿态不重复处理；人工体验和性能结论单独记录。
- 修正持久实例已被本帧选中、同时收到来源删除时的提交异常；当前帧保留合法快照和模型引用，后续视图不再保留已删除实例，快速复用的来源寿命覆盖整个原生提交。
- 主世界与 Sable 区段共用请求、准备和容量控制；结构成员按来源变化维护，父姿态与成员内容分开更新，保留旧几何、完成后发布及资源退休。
- 资源重载后相同区段成员仍会重新绑定平台代际；退出世界同步关闭来源空间和原生实例场景，防止旧身份跨世界残留。
- 稳定局部模型在参数打包前复用已接受状态，Flywheel 父变换与光照变化不再要求逐个重传所有成员；动画、材质、捕获回退和完整场景参与保持有效，实际性能结果另行记录。
- 修正巨大 Sable 结构因空区段重复延期、后续有效区段无法获得构建机会而不显示的问题；真正未到达的数据仍保留原几何，版本、容量和 GPU 完成后发布保护保持有效。同一地图副本已确认结构恢复，完整人工体验待验。
- LOD 后台进度变化时，未持有近远景交接残留的近景覆盖表不再重复重建；近景、空区段、材质及交接依赖仍使缓存失效，不删减远景几何。
- 支持纹理在图像存储创建前设置采样参数，后续创建存储保留已配置的过滤和寻址，避免异步加载期间触发未初始化采样器异常。
- 将区块请求合并、来源等待、快照、后台编译／打包、预算、GPU 完成后发布和旧资源退休接为统一流水线；静态页与元数据复用，改善连续加载、移动与放挖响应。保留完整几何和历史；实际收益与资源代价见开发记录，人工体验待验。
- 未安装 Sable 时直接跳过其来源查询，避免纯原版实体密集场景中反复类加载失败；已安装来源的正常执行与显式错误保留。
- 分开菜单背景压暗与真实界面覆盖，保留 HUD 原有压暗、颜色和绘制顺序；暂停本身不再禁止帧生成，实际全屏菜单模糊、加载覆盖、替换背景及无效输入仍关闭。已确认实际生成帧与启停；人工视觉验收尚未进行，后续补做。
- 反色准星保留原有颜色运算，并作为覆盖界面提交，不再写入帧生成的无界面世界输入；不将其描述为在生成背景上重新计算反色。
- 按实际内存预算保留不变的局部部件与附加层绑定，避免大量小型外观版本因固定项数退回逐帧展开；场景表及 TLAS 仅在对应内容变化时重新上传或构建，保留动画、纹理换代和在途资源保护。
- 修正室内站立／下蹲时 SHARC 训练首段与画面可见性不一致引起的照明及帧时间突变；反弹后的完整世界传光保持不变。
- 区段正常重新编译时保留本帧有效的方块实体快照，避免告示牌等漏交一帧；卸载、重定位和世界切换仍使旧所有者失效。
- 修正多几何刚性实例的材质命中表及上帧变换层级，避免错误材质和后续实例运动历史串用。
- 将已验证的原版实体、部件、方块实体、世界物品和粒子接到显式状态与局部模型请求，复用不变定义及有序附加层；保留动画、颜色、物理发光和资源重载，特殊原执行残留单独登记。
- 修正 Voxy 合法请求范围超过驻留网格预算时的容量合同冲突；完整根覆盖域与网格、在途构建的容量分别管理，保留有效代理与资源退休。
- 将物品展示框的稳定烘焙模型接入资源发布与实例状态路径，省去热帧完整 recipe 比较；保留模型选择、物品调色、附加效果与重载，未接管的动态来源继续完整执行。
- 缩小捕获器中未使用的父类固定缓冲表，按实际破坏覆盖层需求创建辅助捕获器，并在收齐批次后跳过空记录整理；保留原渲染回调、刚性模型与批次生命周期。
- 减少实体几何反向成对面的资格检查开销，保留薄片两侧外观、必要的拓扑修正与运动历史；不通过减少几何或关闭检查提速。
- 限制字体生命周期登记只覆盖真正待提交的文字批次，减少实体密集场景中无关缓冲源触发的周期性长帧；保留资源重载时的旧字体页保护。
- 加载页淡出不再调制下层主菜单的全景透明度，避免菜单自身淡入被再次压低、覆盖层结束时突然恢复；保留原有过渡时长与混合公式。
- 恢复实体交给来源渲染器前的帧间朝向插值，避免船只转向按游戏 tick 跳变；矿车回退及其他消费相同参数的渲染器共用该规则，不改变其内部动画与世界传光。
- 隔离透明表面的反射与折射射线状态，避免反射分支使连续折射重新显示第一人称自身；优先级续追踪同样按实际事件保留成像身份。
- 自身轮廓／优先级文字继承摄像机所有者隐藏，保留其世界传光和原有物理材质。
- 船内水面排除域由原版遮水盖片延伸到实际船底，保留船外及其他合法水面。
- 补齐旋风人风层的主 UV 动画、颜色调制和来源 alpha 丢弃阶段。

- 修正 Flywheel 0.01/0.1 裁切阈值，以及已知裁切程序被名称中的 solid 误判为可跳过透明命中的路径。
- 重载后按实际 FontSet 身份拒绝退休缓存，保留原始异常与旧 GPU 引用的退休顺序。
- FSR 帧时间归属改为连续视图而非交换链槽位；SDK 未接受输出或初始化未就绪时使用既有回退，并使下一帧历史失效。
- 保留的可选透明线策略使用真实 blend 因子，区分普通加法、闪电与 glint；默认不透明不变。
- 字体重载时注销旧图集并退休引用它的未提交文字批次，避免 F3+T 后访问已关闭字体页造成崩溃或使用错误图集。
- 接通世界事件中的显式线请求，保留来源宽度、颜色和绘制姿态，补齐 Sable 线包装器的矩阵转发。
- 模型轮廓使用独立截面参考，避免切线被当成绕轴参考；来源批次布局变化时不复用不兼容的运动历史。
- 恢复加载画面退出时的默认混合状态，修正首个主菜单按钮淡入时可能使用遗留状态的问题。
- 通用线条转几何保留绘制时的局部姿态，使旋转结构与活动部件的轮廓截面随之转动；校正普通与 DEBUG 线段的顶点布局处理。

### 新增

- 增加实际显示器 HDR 输出与自动 SDR 回退，支持 HDR10 和 scRGB；世界和界面参考白独立，峰值可自动读取或手动设置。

- 增加按实际画面亮度计算的 Bloom，提供独立开关与强度；保留既有曝光、GUI 和补帧分类。

### 变更

- 持久光栅缓冲保留有上限的旧版本缓存，只在在途引用结束且尺寸／用途匹配时复用，减少 Veil 等显式缓冲来源的重复分配；变化上传和资源退休保持独立。
- 视频设置新增独立的随机覆盖边界雾开关，默认开启；淡出范围调整为有效远景半径的 95%～100%，覆盖率采用越远下降越慢的二次曲线，世界传光与真实介质吸收保持不变。
- 世界暂时移除距离、维度、流体、细雪及失明／黑暗视野雾；保留屏幕覆盖和水／玻璃的 PT 吸收。
- 远景使用随机距离截止淡出，直接成像和连续折射共享范围，传光与反射仍使用完整几何；Voxy 范围由配套 Extra 提供。
- 主世界与下界按原始群系雾色调整天空散射，末地改用资源包天空纹理的线性平均色；下界和末地提供柔和环境照明，不添加日月方向光。天气统一削弱散射与直接光，雷暴关闭日月直接光。
- 将原版适配、公共接入平台与 Native 执行按职责接通，增加有界的持久实例变化提交及按需接管状态页面；完整几何、历史和 GPU 退休保持原有规则。本轮候选待人工验收，性能未定。
- 第三方专项适配迁入独立的 Radiance Extra，组合使用配套发行 JAR；本体不再内嵌或反向依赖适配仓库。现有 GUI、世界查询、LOD 取舍和效果语义不变。
- 原版四边形粒子使用共享局部面和逐粒子姿态，保留原有动画、颜色、透明度、照明与重载；程序化网格、GUI、附件与呈现增加可选的请求归属核对，不改变默认画质或启用性能计时。
- 原版部件模型按已确认的烘焙来源复用局部几何，各对象仍独立更新动画、可见部件和外观；盔甲、眼睛及其他需要完整表面合成的内容保留原处理，来源被未登记修改时自动退回。
- 对生成规则稳定的原版绘画复用完整局部网格与加速结构，继续更新姿态和材质状态；未知生成器修改、特殊绘制与容量不足时保留完整捕获。
