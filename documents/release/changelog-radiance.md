# Radiance 更新日志

适用于 Minecraft 1.21.1 / NeoForge。

## [未发布]

适用于 Minecraft 1.21.1 / NeoForge。

### 修复

- 缩小捕获器中未使用的父类固定缓冲表，按实际破坏覆盖层需求创建辅助捕获器，并在收齐批次后跳过空记录整理；保留原渲染回调、刚性模型与批次生命周期。
- 减少实体几何反向成对面的资格检查开销，保留薄片两侧外观、必要的拓扑修正与运动历史；不通过减少几何或关闭检查提速。
- 限制字体生命周期登记只覆盖真正待提交的文字批次，减少实体密集场景中无关缓冲源触发的周期性长帧；保留资源重载时的旧字体页保护。
- 加载页淡出不再调制下层主菜单的全景透明度，避免菜单自身淡入被再次压低、覆盖层结束时突然恢复；保留原有过渡时长与混合公式。
- 恢复实体交给来源渲染器前的帧间朝向插值，避免船只转向按游戏 tick 跳变；矿车回退及其他消费相同参数的渲染器共用该规则，不改变其内部动画与世界传光。
- 隔离透明表面的反射与折射射线状态，避免反射分支使连续折射重新显示第一人称自身；优先级续追踪同样按实际事件保留成像身份。
- 自身轮廓／优先级文字继承摄像机所有者隐藏，保留其世界传光和原有物理材质。
- 船内水面排除域由原版遮水盖片延伸到实际船底，保留船外及其他合法水面。
- 补齐旋风人风层的主 UV 动画、颜色调制和来源 alpha 丢弃阶段。
- 为已知重合附加层保留有序覆盖、独立 UV 和原有颜色／透明度，普通装饰与物理发光分开处理；保护末影龙眼睛的完整捕获路径。
- 眼睛附加层可与覆盖其全部可见面的身体表面合成，保留独立颜色与朝向；避免蜘蛛、末影人眼睛在重合层中被遮挡，传光查询仍接收其物理发光。
- 保存充能苦力怕电弧绘制时的纹理变换，恢复主 UV 滚动；普通实体与世界事件共用处理，附魔纹理和其他模型缓存不重复变换。
- 保留各 draw 的独立颜色、alpha 丢弃阶段和眼睛层调色，避免批次收尾状态污染已捕获内容；能量层补齐来源裁切。
- 修正 Flywheel 0.01/0.1 裁切阈值，以及已知裁切程序被名称中的 solid 误判为可跳过透明命中的路径。
- 重载后按实际 FontSet 身份拒绝退休缓存，保留原始异常与旧 GPU 引用的退休顺序。
- FSR 帧时间归属改为连续视图而非交换链槽位；SDK 未接受输出或初始化未就绪时使用既有回退，并使下一帧历史失效。
- 保留的可选透明线策略使用真实 blend 因子，区分普通加法、闪电与 glint；默认不透明不变。
- 字体重载时注销旧图集并退休引用它的未提交文字批次，避免 F3+T 后访问已关闭字体页造成崩溃或使用错误图集。
- 接通世界事件中的显式线请求，保留来源宽度、颜色和绘制姿态，补齐 Sable 线包装器的矩阵转发。
- 模型轮廓使用独立截面参考，避免切线被当成绕轴参考；来源批次布局变化时不复用不兼容的运动历史。
- 恢复加载画面退出时的默认混合状态，修正首个主菜单按钮淡入时可能使用遗留状态的问题。
- 通用线条转几何保留绘制时的局部姿态，使旋转结构与活动部件的轮廓截面随之转动；校正普通与 DEBUG 线段的顶点布局处理。

### 新增

- 增加默认关闭的材质状态批量桥接实验，保留原有回调、状态恢复与纹理写序；限定功能回归通过，但未证实稳定整帧收益。

- 为指定 Voxy 本地 NeoForge 版本增加可选远景 PT 后端，复用来源 LOD 与压缩面，采用 Vulkan 持久几何及近远景交接；不内嵌 Voxy，不恢复被接受的来源细节取舍。

- 视频设置增加普通半透明模式选择，保留随机覆盖默认值，提供前景受光与实际追踪背景的线性混合；Vanilla PT 和 Advanced 均可选择，不改变物理透射与其他专用材质分类。

### 变更

- 对生成规则稳定的原版绘画复用完整局部网格与加速结构，继续更新逐格光照、姿态和材质状态；未知生成器修改、特殊绘制与容量不足时保留完整捕获。
- 对满足既有条件的普通烘焙模型复用局部几何和独立实例姿态，减少每帧顶点展开及重复配方克隆；原动画、材质回调、附加层回退、重载与资源退休保留，不将全部实体强制实例化。
- 减少静态区块每帧重复整理和复制几何信息，保留完整场景、相机运动、历史和动态内容更新；本轮尚未确认整帧流畅度改善。
- 内容不变时复用路径追踪着色命中表，减少重复准备与上传；内容变化和管线重建使用独立版本，保留 GPU 在途引用及重载保护。
- 收敛捕获空间、目标路由、跨语言 ABI、表面政策、最终位置、视图帧及两套 PT 的共同表面函数；原 renderer 回调、查询规则、完整几何和在途资源退休保留。
- 限制实际拒收诊断的去重键数与文本长度，合法绘制不新增该锁；未知程序及全亮物理贡献保持现有政策并明确待决定边界。
- 世界几何线默认不透明，保留真实来源 alpha 的捕获与可显式恢复的透明实现；屏幕线与 Create 模型框规则不变。
- 世界后置光栅改为显式用途允许名单；Veil 几何排空保留在生产阶段，后处理单独安排，屏幕与离屏效果保持独立。
- 静态区块按实际发布变化更新场景快照，减少不变帧重复整理地址、材质和命中组；完整几何、相机与外部结构历史、GPU 完成条件和资源退休保持原有规则。
- 项目内客户端默认启用有界轻量取证和外置 Aftermath 基础采集；私有 SDK 不进入发行包，重型验证按需开启。
- 将区块 CPU 拓扑准备移出共享锁，保留发布时的代际、版本与所有者校验；世界内性能改善尚未完成对照验证。
- 统一直接成像、连续折射、传光与优先级通道；不可见背面保留双面传光，第一人称手部仅接收世界照明。
- 优先级文字、轮廓与锁定标记使用实际 PT 材质受光，保留来源覆盖率、发光和合成顺序。
- 按来源船内遮罩过滤实际水面，保留船外及其他合法水面，移除材料级水面重复命中豁免。
- 升级仓库模板至 2.0.2，接入 `platform` 构建 API、YAML 格式覆盖与本地模组元数据识别修正，保留产品行为。
- 升级 NeoForge、Sable 与公共 Java 依赖，刷新 Vulkan 工具链；兼容模组的内嵌依赖继续跟随父发行包。
- 原生重新配置时刷新 SDK 工具路径，兼容契约测试使用当前配置的 Sable 版本。
- 补齐验证探针的原生采集器资源，启动验证同时检查实际挂接；采集器仍排除在产品包之外。
- 升级仓库模板至 2.0.0，统一构建插件与规范附件位置，保留项目运行和渲染行为。
- 将构建迁入 Target 与组件结构，合并 MCVR 为 `native_renderer`，保持玩家可见渲染和引导逻辑。
- 将诊断模组改为验证专用探针，游戏无关工具移入 `render_diagnostics`。
- 编译 NeoForge 更新到 21.1.259，支持下限仍为 21.1.62，兼容发行版本保持固定。
- 历史台账、relay 与闭合审计归档，文档主语言改为简体中文。
- 升级仓库模板至 1.2.1，二进制资源按 Git 属性跳过文本检查，并检查模板名称残留。
- 原生格式检查支持执行时从 PATH 或 Visual Studio 查找 clang-format，缺失时给出安装说明。
- 对齐构建配置、双语首页标题与 NOTICE 来源结构；CI 使用构建自身的原生工具查找。
