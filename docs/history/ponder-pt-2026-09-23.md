# Ponder PT archive: 2026-09-23

Status: archived by user decision; the default Ponder raster path replaces PT.
Evidence: source and pinned Ponder 1.0.82 / Create 6.0.10 bytecode; runtime evidence is recorded
in the [development ledger](../DEVELOPMENT_LEDGER.md#2026-09-23-ponder-raster-restoration-and-create-stencil-crash).

## Decision and unresolved symptoms

The user requested disabling and preserving Ponder PT after flat-colored previous/next scenes,
abnormal water reflections and leaking/flickering crop edges. Those symptoms are archived,
not accepted as repaired. This decision supersedes the earlier requirement that Ponder transition
worlds share PT lighting. The original scene, camera, animation, transition and drawing order now
run through the Vulkan raster translation. No OpenGL context or PT screenshot replacement is used.
The main world remains path traced; unrelated world shading, face rules and safe resource retirement
are retained. Future generic UI PT work requires separate prioritization.
