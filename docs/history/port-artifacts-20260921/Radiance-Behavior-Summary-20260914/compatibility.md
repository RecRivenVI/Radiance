# Radiance 第三方兼容行为摘要

审计对象是 Radiance `1.21.1-neoforge` 工作树，基线为 `414d8e3`，以及同一工作区的 MCVR `develop` 工作树，基线为 `9905c81`。这里的“上游”指对应基线树，“当前”指本次审计时的脏工作树。414d8e3 的 `radiance.mixins.json` 和 Java 树没有这些第三方兼容包；当前兼容条目都是新增路径或直接入口改动。

本次只做源码、Mixin 配置和 MCVR 外部 chunk/entity API 的静态阅读，没有构建、启动游戏、加载第三方 mod、发起网络请求或修改仓库。父任务提供的 clean client 运行只能证明当前无第三方组合的启动路径；它不能证明下面任何 mod 组合的加载、ABI、画面或交互接受。除特别标明外，验证状态均为静态通过、第三方运行待验证。
