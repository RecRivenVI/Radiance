2026-09-14 · 只读分析；以下建议不等于已经作出删改决定。

**建议方向：以原版 Radiance/MCVR 行为为底，保留必要移植、实质第三方兼容和可靠防护；主动外观变化逐项选择；详细诊断收敛为可关闭的调试能力。**

## 检测与上报的具体结论

- Vulkan 重型诊断默认开启，`MCVR_VULKAN_DIAGNOSTICS=0/false/FALSE` 可关闭；包含资源名、地址关联及检查点。Release validation 默认关闭，DEBUG 请求开启。
- 设备丢失时写本地日志，存在厂商二进制数据时写 `mcvr-device-fault.bin`。NGX callback 和资源明细也是本地输出；它们与实际错误判断可以拆开。
- Sable 摘要约每秒一次，无诊断开关，无 Sable 时也会输出零计数。VMA 普通30秒、压力达到80%时5秒输出一次，分配失败强制记录。
- 粒子 CrashReport 原本就存在于上游；Shader/config 文件用于正常功能，不应仅按 report/dump/write 的字样清理。

**自有远程上报：** 已搜索当前 Java/C++ 的 HTTP、Socket、自定义网络包、上传/遥测入口并回读命中，未发现自动上传诊断日志的实现。URLConnection 用于 JAR 资源，metadata 包含普通网站链接。此结论不覆盖闭源 SDK 内部、Minecraft/Loader 正常网络活动，也不是网络抓包证明。

## 按你的偏好优先处理

1. **保留兼容骨干**：Create ValueBox、Sable 外部区块/变换/实体、Simulated 图纸替代，以及它们共用的 JNI、顶点/材质和资源生命周期支持。
2. **防护与伪成功分开**：Flywheel/Veil/Ponder 的取消 GL 调用可作为临时保护，但 synthetic FBO ID/COMPLETE 不代表内容已绘制。应收窄空操作、补真实桥接。
3. **单独选择视觉变化**：星场与被移除的星空参数、glint 材质、名字牌 alpha、粒子/文字 priority 路由。名字牌透明度、白灰粒子、非活动帧率选项是较明确的上游行为恢复候选。
4. **独立处理正确性问题**：R01 DLSS 宏回归优先修正；R02 辅助纹理级联释放补验证；N08 法线矩阵先用非均匀缩放场景确认，不能直接回退而损伤 Sable 变换。
5. **诊断独立收敛**：保留实际错误判断和关键本地报告；重型追踪、周期日志按需启用；继续保持 Early Display 隔离。

同一文件常混有移植、兼容、修复和诊断。恢复上游外观时应按数据语义和调用链拆分，避免整文件回退连带删除第三方几何、alpha 编码或 JNI 支持。GPU TimerQuery 接口更准确属于既有计时能力的 Vulkan 适配/诊断基础，不直接算新的玩家功能。
