# 阅读顺序与材料等级

以本轮根整合的编号报告、`ledger.json`、`coverage.json`和两个中文CSV为最终审计结果。

1. `01-审计基线.md`：固定commit、两类比较、原始证据及计数口径。
2. `02-完整差异台账.md` / `完整差异台账.csv`：功能解释与处理建议。
3. `差异块索引.csv`：从每个原始差异单位反查条目。
4. `03-分类与覆盖.md` / `coverage.json`：覆盖、解释、待确认、遗漏分别统计。
5. `04-待整改清单.md`：诊断全部移除清单与其他待处理项。
6. `05-关键结论与整改优先级.md`：根核验的重要问题与证据边界。
7. `reference-mods.*`、`reference-loaders.*`及最终参考总清单：实际取得/复用/保留/失败状态。

`radiance-java.json`、`mcvr.json`是首轮差异摘录索引，仅保留过程证据；其中模板化解释与PASS字段**不作为最终解释或验收结论**。功能复核稿为 `radiance-java-reviewed.json` / `mcvr-reviewed.json`，再经根核验整合。不能把首轮索引的all-covered/all-explained标志当作最终完成声明。

`reference-research.md`是版本候选交接，不等于已下载、部署或已应用补丁；实际状态以执行结果清单为准。
