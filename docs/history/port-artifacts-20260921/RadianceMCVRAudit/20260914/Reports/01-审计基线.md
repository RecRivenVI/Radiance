## 可复核证据

- 每仓库 `metadata.json / refs.txt / index.txt / status.z / submodules.txt` 固定实际身份、索引和状态。
- `staged.patch / unstaged.patch / head-worktree.patch` 保留binary patch；对应stat文件保留Git原始统计。
- `files.json / units.json / manifest.json` 保存变更路径、单位与全体跟踪/未跟踪文件SHA256；`worktree/`复制所有变化的普通文件，含二进制和新文件。
- `upstream-<sha>.zip`是固定HEAD源码归档；gitlink内容以精确submodule commit引用，不伪装为archive内包含完整依赖源码。
- `submodule-state.json`逐个记录15个子模块HEAD与空dirty状态；`RuntimeLogs/`保存用户提供的三次失败日志，作为历史真实运行证据，**不是本轮重新启动验证**。
- `state-check-*.json`再次检查文件hash、HEAD、branch、index、refs、status及子模块指针。出现外部修改时不会覆盖初始证据，而应报告差异。

被.gitignore忽略的build/run、JNI生成头、core DLL和SPIR-V不属于Git未提交清单。与本轮行为直接有关的发布资源另存补充清单；不把整个运行实例或缓存复制进审计报告，也不宣称审计了所有ignored运行数据。
