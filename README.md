# Radiance

[English](README-en_US.md) | 简体中文

Radiance 将 Minecraft 世界渲染交给 Vulkan C++ 后端，支持硬件路径追踪。Java 模组与原生渲染器现在在同一仓库维护。

## Target

| Target | Loader | Java |
| --- | --- | --- |
| `1.21.1-neoforge` | NeoForge 21.1.256 | 21 |

## 快速开始

安装完整发行 JAR；GAME Maven 构件仅用于开发集成。PBR 资源包可直接加载。当前二进制只供本地验收，公开分发许可仍未确认。
