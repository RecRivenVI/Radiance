# Radiance

English | [简体中文](README.md)

Radiance replaces Minecraft world rendering with a Vulkan C++ backend and supports hardware path tracing. The Java mod and native renderer are maintained in one repository.

## Target

| Target | Loader | Java |
| --- | --- | --- |
| `1.21.1-neoforge` | NeoForge 21.1.256 | 21 |

## Quick start

Install the complete distribution JAR; the GAME Maven artifact is for developer integration only. PBR resource packs load directly. Native binary redistribution approval remains unresolved; current packages are for local validation.
